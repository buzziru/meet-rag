# S11b 연도·위원회 표기 차이 추출

S11 추출기(D-21)가 놓치는 표기 차이 세 가지를 더한다(PR #53 사용자 코멘트, 2026-10-12). 화자가 다양해 연도·위원회를 부르는 방식이 조금씩 다르기 때문이다. G3 측정 뒤에 더하는 새 규칙이므로 규칙은 G3를 보지 않고 표기 관행과 국회 공식 약칭으로 정하고, G3 측정은 한 번 해서 D-21처럼 기록한다(사용자 결정).

## 만드는 것

- `src/rag/conditions.py`: 새 필드 `year_ref`, 두 자리 연도, 위원회 약칭 표
- `configs/config.yaml`: `conditions.committee_aliases`(약칭 → 위원회 이름 목록)
- `notebooks/13_02_조건표기차이.ipynb`: 새 규칙의 발화율·정밀도·적중률과 `year_ref`와 회의 연도의 차이 분포

## 규칙

### `year_ref`(새 필드)

- `YYYY년도`, `YYYY 회계연도`, `YYYY연도`를 `date`가 아니라 `year_ref`로 뽑는다. 값은 `YYYY`
- `date`에 섞지 않는 이유: `년도`가 가리키는 해는 회의 연도와 어긋날 수 있다(`2019년도 예산안`은 보통 2018년에 심사, `2018회계연도 결산`은 2019년에 심사). `year_ref`를 문서 연도와 어떻게 맞출지는 EXP-003에서 정한다
- 측정에서는 "맞는다"를 정하지 않고, 정답 문서 연도에서 `year_ref`를 뺀 차이의 분포를 낸다

### 두 자리 연도

- `'YY년 [M월 [D일]]`(앞에 `'`)은 `date`로, `'YY년도`·`YY년도`는 `year_ref`로 뽑는다
- 앞에 `'`가 없는 `YY년`은 뽑지 않는다. `19년 만에`, `19년간` 같은 기간 표현과 겹친다
- 네 자리로 바꿀 때 `YY ≤ 30`이면 `20YY`, 아니면 `19YY`로 둔다. 코퍼스 회의 연도는 1996\~2023이다

### 위원회 약칭 표

- `conditions.committee_aliases`에 국회에서 쓰는 공식·관용 약칭을 둔다(예: `법사위` → `법제사법위원회`, `예결위` → `예산결산특별위원회`, `외통위` → `외교통일위원회`·`외교통상통일위원회`). 한 약칭이 시기별로 여러 위원회를 가리키면 모두 적고, 추출은 그 이름을 모두 낸다
- 표의 위원회 이름은 모두 값 사전(`committee_name`의 반 표기를 뗀 값)에 있어야 한다. 테스트가 확인한다
- `국회 본회의`(띄어 쓴 표기)를 코퍼스 값 `국회본회의`로 맞추는 항목도 표에 둔다. 이 항목은 D-21 G3 측정에서 놓친 사례로 관찰한 표기라 G3를 보지 않고 정한 규칙이 아니다(D-22 단서)
- 기존 `원회` 떼기 약칭(`국방위`)과 긴 값 우선 규칙은 그대로다. 표의 약칭도 같은 정규식에 넣어 긴 값이 이긴다

### 바꾸지 않는 것

- 기존 필드의 규칙(D-21)과 이름·직위 조건. 기존 필드는 새 규칙으로 값이 더해질 수만 있다(`date`에 두 자리 연도, `committee_name`에 약칭)

## 노트북과 결정 순서

1. 규칙을 넣고 두 세트의 조건 파일을 다시 쓴다
2. `notebooks/13_02_조건표기차이.ipynb`를 쓴다. S11 노트북과 같은 정확도 표(유형×필드)를 낸다. 새 규칙 때문에 값이 생긴 질의 수, `year_ref`의 발화율과 정답 문서 연도와의 차이 분포(-1, 0, +1, 그 밖), 약칭으로 뽑힌 위원회의 정밀도를 따로 낸다. 질의 원문은 오추출 몇 건만 보인다(D-10)
3. 노트북을 사용자에게 보이고 기록한다(D-22). 측정 뒤 고치는 것은 S11과 같이 결함만이다

## 완료 기준

1. `uv run python -m rag.conditions search.queries=multidoc`가 600줄, `search.queries=summary_q`가 3,016줄을 쓰고, 두 번 실행한 SHA-256이 같다
2. 새 규칙을 끈 상태와 비교했을 때 기존 필드에서 사라진 값이 없다(값이 더해지기만 한다). 노트북이나 테스트로 확인한다
3. `year_ref`, 두 자리 연도(통과: `'19년 3월`, `19년도` / 거부: `19년 만에`, `19년간`), 약칭(통과: `법사위`, `국회 본회의` / 표의 이름이 사전에 있음) 단위 테스트를 둔다. 테스트 문장은 직접 쓴다
4. `uv run pytest -q`, `uv run ruff check .` 통과
