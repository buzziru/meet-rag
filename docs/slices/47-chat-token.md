# S47 화면 점검용 채팅 열기

Vercel 페이지는 비공개 Space를 토큰 없이 부를 수 없어(404) 채팅이 "서버에 연결하고 있습니다"에 머문다. 공개 전에 이 페이지에서 답변을 볼 수 있게, 페이지가 사용자 브라우저 저장소의 토큰으로 Space에 연결한다(D-88 결정 3).

## 만드는 것

- **토큰 읽기**: `deploy/web/app.js`가 브라우저 저장소(`localStorage`)의 토큰을 읽어 `Client.connect`의 `token` 옵션으로 넘긴다. 토큰이 없으면 지금과 같다. S41에서 지우기 쉽게 이 두 줄만 더하고 주석에 지울 시점을 적는다
- **안내 절차**: 토큰을 만들고 넣는 단계를 이 문서 "토큰 절차"에 적는다. Space와 다른 코드는 바꾸지 않는다

## 결정 사항

1. **토큰을 넣는 방법(사용자 결정 2026-11-05)**: 브라우저 콘솔에 한 줄 입력한다(`localStorage.setItem("hf_token", "…")`). 코드는 두 줄이고 화면이 그대로라 방문자가 보는 화면과 같다. 고르지 않은 안은 페이지 입력칸이다. 화면 코드가 늘고 공개 전까지 점검용 칸이 남는다
2. **확인 순서(메인 적용, D-88과 PR #229)**: PLAN은 병합 뒤 안내로 적었지만 미리보기 배포를 다시 켜 병합 전에 볼 수 있다. 입력→동작: 페이지 커밋을 올리면 사용자가 그 브랜치의 미리보기 주소에 토큰을 넣고 답변을 확인한 뒤 병합한다. 저장소는 주소마다 따로라 production에서도 쓰려면 병합 뒤 한 번 더 넣는다
3. **OpenRouter 호출(사용자 승인 2026-11-05)**: 지어낸 질의 5번 이하, $0.01 이하로 본다(1,000질의당 약 $0.37, S39b). 재정렬은 무료 ZeroGPU 할당량 안이다. Colab과 유료 HF 하드웨어는 쓰지 않는다. 연결 확인은 질의 없이 하고, 답변 확인에서만 부른다
4. **Aside(사용자 결정 2026-11-05, ADR-0099)**: 토큰이 든 브라우저에서 Aside가 채팅까지 점검한다. 토큰 값은 프롬프트와 보고에 적지 않는다

## 노트북과 결정의 순서

데이터를 보고 정하는 결정이 없어 노트북을 쓰지 않는다.

## 토큰 절차

1. 사용자가 https://huggingface.co/settings/tokens 에서 Fine-grained 토큰을 만든다. 이름은 알아보기 쉽게 짓고(예: `meet-rag-screen-check`), 권한은 저장소 `ingyoun/meet-rag`의 읽기만 준다(D-88 결정 3)
2. 사용자가 대상 페이지에서 개발자 도구 콘솔을 열어 `localStorage.setItem("hf_token", "발급받은 값")`을 넣고 새로 고친다. 값을 대화나 저장소에 적지 않는다
3. 폐기: S41에서 토큰 코드를 지우는 시점에 메인이 알리고 사용자가 같은 설정 화면에서 지운다(D-88 결정 3)

## 완료 기준

질의는 지어낸 것만 보낸다. 2\~5는 토큰을 넣은 브라우저의 미리보기 주소에서 본다.

| # | 명령 | 기대 결과 |
| --- | --- | --- |
| 1 | `uv run pytest -q`, `uv run ruff check .` | 통과 |
| 2 | 토큰 없는 브라우저 저장소로 미리보기 주소를 연다 | 지금과 같이 연결 대기 문구가 보이고 콘솔 오류로 멈추지 않는다 |
| 3 | 토큰을 넣고 새로 고친다(Aside, 질의 없음) | 연결 문구가 사라지고 연도 선택 칸이 채워진다 |
| 4 | 지어낸 질의 1번(Aside) | 답변이 조각으로 나오고 근거 칸이 채워진다. 회의 정보가 문장 끝 괄호로 보인다 |
| 5 | 사용자가 같은 주소에서 답변을 본다 | 답변 표시를 의도대로 확인한다(S45 완료 기준 5) |
| 6 | 페이지 커밋 뒤에 문서 커밋을 함께 push한다 | 미리보기가 빌드되는지 결과 절에 적는다. 건너뛰면 `ignoreCommand`를 끝 커밋이 아니라 push 범위를 보게 고친다 |
| 7 | 값 대조: `git grep`으로 저장소에 토큰 값이 없고, Aside 보고에 토큰 값이 없다 | 없음 |

## 수정 허용 파일

`deploy/web/app.js`, `deploy/web/vercel.json`(완료 기준 6에서 건너뛸 때만), 이 문서, `docs/PLAN.md`, `docs/PLAN-done.md`, `docs/slices/45-meeting-info.md`(완료 기준 5 결과)

## 범위 밖

- Space 공개, Vercel 보호 설정 해제, 대표 주소(S41)
- Gradio 화면 제거와 로컬 확인 `?api=` 정리(S48)
- 첫 토큰 3초 재측정(S41에서 1회)
- 토큰이 틀렸을 때의 안내 문구. 틀리면 연결 대기 문구에 머문다. 사용자만 쓰는 점검용 코드라 더하지 않는다

## 감수하는 것

페이지가 불러오는 외부 스크립트(`@gradio/client`, jsDelivr)는 브라우저 저장소를 읽을 수 있다. 토큰이 이 Space 읽기만 허용하고 S41에서 폐기하므로 받아들인다(D-88 "감수하는 것").
