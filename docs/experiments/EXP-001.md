# EXP-001: hybrid 검색 (dense + BM25 Kiwi, RRF)

## 가설
- 어휘 매칭(BM25)을 dense 검색에 RRF로 더하면, dense가 놓친 정답 문서(고유명사·법안명·숫자처럼 표면 어휘가 결정적인 질의)가 상위로 올라와 dev-full Recall@5가 오른다. 질의가 정답 문서를 보고 생성돼 어휘가 많이 겹친다(SPEC 해석의 한계 1항)는 점도 BM25에 유리하다
- 보조 관찰: multi-doc `law`·`questioner` 질의는 날짜·위원회·위원 이름으로 회의를 지목한다(D-16 관찰). 이름이 본문에 있는 문서는 BM25가 dense와 다르게 찾을 수 있다

## 기준 실험
- 베이스라인 S5 (KURE-v1, 512/64, numpy 전수 검색, `chunk_pool` 200). dev-full Recall@5 0.8584(D-09)
- 기준 순위: single-doc `data/runs/kure-v1-fixed-512-64-dev-full.csv`(SHA-256 `f15688433784bd1682d6063333150d721957a7233758c512c1a98d8da18bbbe2`), multi-doc `data/runs/kure-v1-fixed-512-64-multidoc.csv`(SHA-256 `8f14dc808c16b94afac5b4167c7e63088a27410290e1f113135d537643bf8289`)

## 바꾸는 것
- `retriever.type`: dense → hybrid
- BM25 검색기 추가
  - 단위: dense 인덱스와 같은 청크(`chunks.jsonl`, 512/64, 118,039개). 청크 점수에서 문서가 처음 나온 순위를 문서 순위로 쓴다(SPEC 지표 절과 같은 규칙)
  - 토큰화: Kiwi 형태소 분석 후 체언·용언 어간·어근·외국어·한자·숫자(태그 `NNG` `NNP` `NNB` `NR` `NP` `VV` `VA` `XR` `SL` `SH` `SN`)의 형태만 남긴다. 조사·어미·접사·부호는 버린다
  - 점수: bm25s Lucene 방식, k1 1.5, b 0.75(라이브러리 기본값)
- 결합: 두 검색기의 문서 순위를 RRF로 합친다. 점수 = Σ 1/(60 + 순위), 검색기마다 상위 100개 문서까지, 가중치 같음. 동점이면 dense 순위가 앞선 문서를 먼저 둔다. 상위 10개 문서를 순위 파일에 쓴다
- 파라미터는 위 값으로 고정하고 dev-full에서 조정하지 않는다. 결합 가중치·RRF 상수·태그 집합 조정은 결과를 보고 필요하면 새 가설로 백로그에 올린다
- 순위 파일 이름에 검색기 종류를 넣는다(`…-hybrid-dev-full.csv`). dense는 지금 이름 그대로라 기준 파일을 덮어쓰지 않는다

## 고정 조건
- SPEC 평가 프로토콜 v1(`configs/eval/spec_v1.yaml`) / 임베딩·청킹·dense 인덱스·질의 임베딩 캐시 재사용(재임베딩 없음) / config: `configs/exp/exp001.yaml`
- BM25 인덱스는 로컬 CPU에서 만든다(1,000청크 5.5초 실측, 전체 약 11분 예상). Colab·유료 API를 쓰지 않는다

## 판정 기준 (실행 전 확정)
- SPEC 판정 절 그대로: dev-full Recall@5 차이를 회의 단위 paired bootstrap(10,000회, seed 20260929)으로 계산한다
- 채택: 95% 구간 하한 > 0 이고 점 추정 차이 ≥ +1.0%p
- 기각: 95% 구간 상한 < 0
- 보류: 그 밖
- multi-doc 결과는 판정에 쓰지 않고 결과 절에 관찰로 적는다(SPEC 보조 관찰)

## 실행
- dev-small 확인(노트북): `uv run python -m rag.search +exp=exp001`
- single-doc: `uv run python -m rag.search +exp=exp001 index.scope=full` → `uv run python -m rag.eval.compare --base data/runs/kure-v1-fixed-512-64-dev-full.csv --cand data/runs/kure-v1-fixed-512-64-hybrid-dev-full.csv`
- multi-doc: `uv run python -m rag.search +exp=exp001 index.scope=full search.queries=multidoc` → `uv run python -m rag.eval_multi.compare --base data/runs/kure-v1-fixed-512-64-multidoc.csv --cand data/runs/kure-v1-fixed-512-64-hybrid-multidoc.csv`

## 결과
- dev-full Recall@5: 후보 0.9168 / 기준 0.8584 / 차이 +5.84%p (95% 구간 [+4.93, +6.76]%p, 회의 단위 paired bootstrap 10,000회, seed 20260929)
- Recall@1 / @10 / MRR@10: 후보 0.7964 / 0.9450 / 0.8495, 기준 0.7062 / 0.8909 / 0.7707
- 층별: 모든 회의구분·`qna_type`에서 네 지표가 올랐다. Recall@5 증가는 본회의 +10.71%p(112건), 특별위원회 +8.80%p(307건), 예산결산특별위원회 +7.59%p(158건)로 기준 점수가 낮던 층에서 컸다. 단답형 +3.46%p(289건)는 추출형 +6.09%p(2,727건)보다 작다. 층별 구간은 계산하지 않았다
- 상위 5위: 진입 198건, 이탈 22건
- multi-doc(판정에 쓰지 않는 관찰, `pool_id` 단위 bootstrap 95% 구간): 전체 Recall@5 0.4657 → 0.4336, −3.21%p [−5.03, −1.42]. 유형별 conf −2.29%p [−4.94, +0.36](233건), law −7.59%p [−11.69, −3.52](152건), questioner −1.10%p [−4.12, +1.95](215건). law는 Hit@5 −13.82%p [−21.05, −6.58]로 정답을 하나도 찾지 못한 질의가 늘었다. 가설의 보조 관찰(law·questioner에서 BM25가 도움)과 반대 방향이다
- 검색기별 multi-doc Recall@5(dense / BM25 단독 / hybrid): conf 0.829 / 0.661 / 0.806, law 0.299 / 0.121 / 0.223, questioner 0.190 / 0.104 / 0.179. multi-doc 질의에서는 BM25 단독이 dense보다 크게 약하다
- BM25 점수가 0보다 큰 문서가 결합 깊이(100)보다 적은 질의는 dev-full·multi-doc 모두 0건이다(최소 897개). 점수 0 문서가 BM25 순위를 채워 RRF 점수를 받는 경우는 이번 결과에 없다
- 해석의 한계: 평가 질의가 정답 문서를 보고 생성돼 어휘 매칭에 유리하다(SPEC 해석의 한계 1항). single-doc 향상에 이 편향이 섞여 있을 수 있고 분리해 확인하지 않았다. multi-doc 질의는 날짜·위원회·이름처럼 본문에 드문 말로 회의를 지목해 BM25가 약한 것으로 추정한다(원인은 확인하지 않음)
- 근거 노트북: `notebooks/10_01_EXP001_hybrid확인.ipynb`(dev-small), `notebooks/10_02_EXP001_판정근거.ipynb`
- 순위 파일 SHA-256: single-doc `0260382f1e6afe6233528fc3b653167a9fe6c4bd255ec923fb60a34998cb3678`, multi-doc `28918a409dbc9765561e6706f443e565906596068f2ee663590f223a3a0f89ce`
- 실행: `uv run python -m rag.search +exp=exp001 index.scope=full` 9분 42초(BM25 인덱스 생성 포함, 로컬 CPU i5-8250U 4코어, Kiwi 작업자 8), multi-doc 17초 / 코드 커밋 d05fbde, 실행 시점 HEAD 35284ae

## 결론
- 채택. dev-full Recall@5 차이 +5.84%p, 95% 구간 하한 +4.93%p > 0이고 점 추정이 +1.0%p 이상이다. 목표 0.90(D-09)을 넘었다
- multi-doc은 전체 Recall@5 −3.21%p, law −7.59%p로 떨어졌다. BM25 비중을 낮추는 결합(H13)과, hybrid 후보를 재정렬하는 H2에서 회복되는지 함께 본다
