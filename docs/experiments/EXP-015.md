# EXP-015: dense·BM25를 점수 기반 결합(정규화 점수의 가중 합)으로 합침 (H16)

## 가설
- RRF는 순위만 쓰므로 목록 안 점수 차를 버린다. 한 목록에서 1위 점수가 2위보다 크게 높아도(그 목록이 확신하는 경우) 1위와 2위의 기여 차는 1/(k+1) − 1/(k+2)로 같다. 기준(EXP-014, k 20)에서도 결합 손실 81개 중 53개가 살아나지 않았다(`notebooks/25_02_EXP014_원인분석.ipynb`). dense·BM25 점수를 정규화해 가중 합으로 합치면, 한 목록이 정답을 큰 점수 차로 고른 경우가 결합에서 살아나 hybrid Recall@5가 오른다
- 선행 연구: Bruch·Gai·Ingber(2023, "An Analysis of Fusion Functions for Hybrid Retrieval", ACM TOIS)는 정규화 점수의 볼록 결합(convex combination)이 RRF보다 낫고 RRF는 k에 민감하다고 보고했다. 결합 가중치는 적은 예제로 정할 수 있다고 했다(원문 수치는 이 문서에서 다시 확인하지 않았다)
- 반대 방향의 위험: 점수 분포가 목록마다 다르다. dense(코사인)는 상위 점수가 좁은 범위에 몰리고, BM25는 질의 길이·희귀어에 따라 범위가 크게 바뀐다. 정규화가 이 차이를 잘못 맞추면 한 목록이 결합을 지배해, EXP-010(dense 가중치 2)처럼 다른 목록 덕에 맞히던 정답을 잃는다
- 살릴 수 있는 범위: 남은 결합 손실 53개, 약 1.76%p가 상한이다. 잃는 질의를 빼면 SPEC 채택 기준(+1.0%p)에 닿을지는 모른다

## 바꾸는 것
- 결합 방식(`retriever.fusion.method`): `rrf`(기본, 지금과 같음) → `score`
- `score`의 계산(질의마다)
  1. dense 목록과 BM25 목록(각 상위 `depth` 100개 문서)의 문서 점수를 가져온다. dense는 청크 코사인의 문서별 최댓값, BM25는 청크 BM25 점수의 문서별 최댓값(지금 순위를 정하는 값과 같다)
  2. 목록마다 min-max 정규화: (점수 − 목록 100위 점수) / (1위 점수 − 100위 점수). 목록 밖 문서는 0
  3. 결합 점수 = α × dense + (1 − α) × BM25. α = 0.5(결정 사항 1)
  4. 결합 점수로 줄 세운 목록을 하나의 목록으로 보고, 조건 목록이 있으면 둘을 RRF(k 20)로 합친다. 결합 목록 가중치 2, 조건 목록 1(지금 [1, 1, 1]에서 조건 목록이 세 목록 중 하나였던 몫을 유지, 결정 사항 2). 조건 목록이 없는 질의(summary_q 99.9%)는 결합 점수 순서가 그대로 순위다
  5. 최다 일치 필터와 top_k 자르기는 지금과 같다
- 코드: `rag.retrieve`에서 목록과 함께 문서 점수를 넘기고, `fusion.method=score`일 때만 위 계산을 한다. `method`가 없으면 지금과 같은 순위를 낸다(EXP-014 dev-small 재실행으로 확인)
- 순위 파일 `snowflake-ko-fixed-512-64-hybrid-cond-filter-law-ms256-cc-{층}.csv`

## 결정 사항 (실행 전에 사용자가 정한다)
결정(사용자 승인 2026-10-15, dev-small 확인 뒤 dev-full·multi-doc까지 진행): 1은 α 0.5, 2는 A안(결합 목록 가중치 2, 조건 목록 1을 RRF k 20으로), 3은 목록별 상위 100개 min-max. 사용자는 조건 목록이 결합 뒤 RRF로 들어가며 비중이 커지는지 물었고, 가중치 2:1은 지금 세 목록 중 한 장인 조건 목록의 몫을 대략 유지한다는 설명 뒤 A를 골랐다

1. α(dense 몫). 초안은 0.5다. 두 목록을 같게 보는 값으로, RRF의 가중치 [1, 1]과 같은 출발점이다. 단독 성능(dense·BM25 각각의 Recall@5)을 보고 α를 고르면 판정 집합으로 값을 정하는 셈이라 쓰지 않는다. EXP-014와 같이 "값 하나로 방식을 시험한다"는 전제다
2. 조건 목록의 처리. 초안은 결합 목록(가중치 2)과 조건 목록(가중치 1)을 RRF k 20으로 합친다. summary_q 판정에는 거의 영향이 없고 multi-doc 관찰에 영향이 있다. 다른 안: 조건 목록도 점수로 넣기(맞은 필드 수를 정규화). 조건 목록은 원래 점수가 없어(필드 수와 dense 점수로 줄 세움) 초안은 순위로 둔다
3. 정규화 방식. 초안은 목록별 상위 100개의 min-max다. 다른 안: z-score, 이론 범위(코사인 −1~1) 기준. Bruch 외는 정규화 선택에 크게 민감하지 않다고 보고했다
