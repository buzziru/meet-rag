# ADR-0005 `outputs/`는 프로젝트 진행 중 커밋하지 않음

- 상태: 채택
- 날짜: 2026-10-01
- 커밋: 893904f

## 맥락

PR #11 사용자 결정. Colab 실행 기록 같은 산출물을 언제 공개할지 정해야 했고, `.gitignore`에는 쓰지 않는 `output/` 규칙이 남아 있었다.

## 결정

`outputs/`는 진행 중 커밋하지 않고 프로젝트 완료 후 결과 공개 때 공개한다. `.gitignore`의 `output/`을 `outputs/`로 바꾼다. 스테이징되면 감사 위반(P5)이다.

## 결과

`.gitignore`, `.claude/skills/meet-rag`, `protocol-guard` P5.

## 삭제 조건

프로젝트를 마치고 `outputs/`를 공개할 때.
