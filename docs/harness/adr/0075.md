# ADR-0075 생성 EXP 절차의 기준 결과를 DECISIONS 머리 줄에서 읽게 함

- 상태: 채택
- 날짜: 2026-10-28

## 맥락

`.claude/skills/meet-rag/references/gen-exp.md` B1은 생성 EXP의 기준 결과를 파일 경로로 적었다(S25 fr_v1 재채점, ADR-0069·D-59). EXP-018 예외 채택(D-61)으로 생성 기준이 EXP-018 결과로 바뀌어, 이 줄이 옛 기준을 가리키게 됐다. 기준은 채택마다 바뀌는데 경로를 절차 문서에 적으면 채택 PR마다 하네스를 고쳐야 하고, 빠뜨리면 다음 EXP가 옛 기준과 비교한다.

## 결정

- B1은 기준 결과 경로를 적지 않고 `docs/DECISIONS.md` 머리 줄 "현재 기준 설정"을 가리킨다. 머리 줄은 기준을 바꾸는 결정마다 고치게 되어 있다(`docs/CLAUDE.md`, protocol-guard P12)
- 기준 결과 경로가 기본 설정의 `paths.gen_judge`와 다를 때만 report에 `paths.gen_judge=`로 준다는 문장은 남긴다

## 결과

`.claude/skills/meet-rag/references/gen-exp.md` B1 한 줄.

## 삭제 조건

생성 기준을 DECISIONS 머리 줄 대신 다른 곳(config 등)에서 관리하게 되면 그쪽을 가리키게 고친다.
