# ADR-0091 생성 EXP 절차의 끝난 백로그 예시를 뺀다

- 상태: 채택
- 날짜: 2026-11-05

## 맥락

`references/gen-exp.md` 머리 문단이 생성 EXP 예시로 끝난 항목 "H10, H18 등"을 들었다(EXP-023 가이드 관찰). 적용 대상은 앞 문장의 판정 기준으로 이미 정해져 있어 예시가 더하는 정보가 없고, 항목이 끝날 때마다 낡는다.

## 결정

예시를 뺀다. 지금 항목으로 바꾸지 않는다. 바꾸면 같은 이유로 다시 낡는다(ADR-0076).
