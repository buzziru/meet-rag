# ADR-0030 사용자 코멘트를 반영한 뒤 PR 본문 갱신과 코멘트 답글

- 상태: 채택
- 날짜: 2026-10-08

## 맥락

`.claude/rules/git.md` PR 절은 PR을 만들 때의 본문 형식만 정했다. PR #48에서 사용자 코멘트를 반영해 커밋했지만 본문은 첫 반영 시점 그대로였다. 리뷰 가이드의 "판단할 곳"에는 코멘트로 이미 정해진 질문이 남았고, 반영하면서 코멘트를 해석해 정한 부분(가설 단위 셈에서 다른 항목의 EXP가 끼어도 끊지 않음)은 반영 내용과 함께 채팅으로만 보고됐다(사용자 지적 2026-10-08).

## 결정

git.md PR 절에 4번을 더했다. 코멘트를 반영해 커밋하면 push하고 PR을 갱신한다. 본문에 "코멘트 반영" 절을 두어 코멘트마다 반영 내용과 커밋 해시(반영하지 않은 것은 이유)를 적고, 리뷰 가이드의 "판단할 곳"·위험도·변경 절을 지금 diff에 맞춘다. 코멘트를 해석했거나 일부를 반영하지 않았으면 그 코멘트에 답글로 설명한다. 이유는 사용자가 PR 화면에서 diff를 한 번 읽고 판단하기 때문이다. 판단할 곳은 메인이 갱신하고 `pr-briefer`를 다시 부르지 않는다(ADR-0026).

## 결과

`.claude/rules/git.md` PR 절. PR #48에 함께 넣었다(사용자 지적으로 생긴 하네스 변경이고 같은 하네스 PR이다). 같은 PR의 본문 갱신과 코멘트 답글에 바로 적용했다.

## 삭제 조건

PR 본문 대신 다른 수단(PR 리뷰 도구 등)으로 반영 내용을 사용자에게 전달하기로 정할 때.
