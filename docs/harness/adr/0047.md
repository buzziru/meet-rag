# ADR-0047 일일 종합의 Claude 호출을 Messages API 한 번으로 바꾼다

- 상태: 채택
- 날짜: 2026-10-20

## 맥락

- ADR-0046의 워크플로는 `anthropics/claude-code-action@v1`로 Claude Code를 러너에서 실행했다. federation 교환은 성공했지만 첫 요청이 400 `billing_error`("Credit balance is too low")로 거절됐다(run 39363687778, `full_output`으로 확인)
- 조직의 구매 잔액은 $0이고, 프로모션 크레딧($100, 2026-11-04 만료)의 적용 대상은 Agent SDK, API, 배치 API, Playground, 관리형 에이전트다. Claude Code는 없다. 구독제의 클라우드 세션 보너스 크레딧은 claude.ai 로그인 클라우드 세션 전용이고 API 키 인증과 Routines를 제외한다
- 사용자가 크레딧을 사지 않고 API 직접 호출로 바꾸기로 정했다(2026-10-20)

## 결정

- 워크플로는 `.github/scripts/daily_pr_digest.py`를 실행한다. 스크립트가 `gh`로 대상 PR의 본문, 소유자 코멘트·리뷰·줄 코멘트, 바뀐 파일 목록(diff 없이 줄 수만), 열린 종합 이슈를 모아 JSON 하나로 만들고, Python `anthropic` SDK(1.15.0 고정)로 Messages API를 한 번 부른 뒤, 받은 본문으로 `gh issue create`를 한다. 모을 항목이 없으면 모델이 `NO_ITEMS`를 내고 이슈를 만들지 않는다
- 모델은 Claude Opus 5.5(워크플로 env `MODEL`), 인증은 ADR-0046의 federation 그대로다. SDK가 `ANTHROPIC_FEDERATION_*` 환경 변수와 GitHub OIDC 토큰 파일(`ANTHROPIC_IDENTITY_TOKEN_FILE`)로 교환한다. 거절(refusal) 때는 서버 쪽 대체 모델(`fallbacks="default"`)로 넘어간다
- 모델에 도구를 주지 않는다. ADR-0046의 도구 범위·턴 상한·액션의 remote URL 토큰 재설정 문제가 사라진다. 대신 모델이 필요할 때 파일을 더 찾아 읽을 수 없고, 지시 5번(놓쳤을 수 있는 것)은 본문과 바뀐 파일 목록으로만 판단한다. diff 전체는 수천 줄인 PR이 있어 넣지 않는다
- 수동 실행의 `full_output` 입력은 액션 전용이라 지운다. 스크립트가 `stop_reason`·사용량을 로그에 남긴다

## 결과

- 바뀐 파일: `.github/workflows/daily-pr-digest.yml`, `.github/prompts/daily-pr-digest.md`(입력이 JSON으로 바뀜), `.github/scripts/daily_pr_digest.py`(새 파일), ADR-0046 상태
- 비용 추정(측정 전): 입력은 PR 본문 위주라 평소 하루 수만 토큰, PR이 17개였던 10-19 같은 날 약 8만 토큰이다. Opus 5.5 기준 한 번에 약 $0.1\~0.5로 본다. 첫 실행 로그의 `usage`로 확인한다
- API 호출이 프로모션 크레딧에서 차감되는지는 적용 대상 목록에 근거한 추론이다. 첫 실행이 성공하고 콘솔 크레딧 잔액이 줄면 확인된다
