# ADR-0078 미룬 일은 PR 본문만 기록처로 쓰지 않는다, 생성 절차 문서를 D-63·D-64에 맞춤

- 상태: 채택
- 날짜: 2026-11-03

## 맥락

- 2026-11-03 일일 종합이 이슈를 만들지 않아 원인을 보니, PR #189의 미룬 일(`gen-exp.md:35`)이 PR 본문에만 있었다. 일일 종합 프롬프트는 미룬 일이 STATUS·PLAN·후속 PR에 남아 있다고 보고 "참고"로만 분류하므로, 참고만 있는 날은 이슈가 없어 빠진 것이 드러나지 않는다(사용자 지적)
- 같은 날 PR #190은 나중에 확인할 일(`exp019.yaml:7`)을 관찰로 적고 PR 본문에만 남겼다. 규칙(git.md PR 절 3)은 기록처를 적으라고 하지만, 관찰과 미룬 일의 구분이 작성자에게 달려 있고 PR 본문을 보는 단계가 일일 종합뿐이다
- EXP-019 병합으로 기준 judge가 j_v11이 되고(D-63), S31로 judge 실패 처리가 바뀌어(D-64) `gen-exp.md`, protocol-guard P11, pr-briefer R7의 표기가 지났다. `j_v8`을 절차 문서에 적으면 기준이 바뀔 때마다 고쳐야 한다(ADR-0076)

## 결정

- git.md PR 절 3: 나중에 확인하거나 고칠 일은 관찰이 아니라 미룬 일로 적고, PR 본문만 기록처로 쓰지 않는다. 아직 없는 후속 PR로 미루면 STATUS나 PLAN에도 적는다(PR #189의 "뒤 `chore/` PR"이 이 경우다)
- 일일 종합 프롬프트 3·5: 미룬 일인데 남긴 곳이 없거나, PR 본문뿐이거나, 번호 없는 후속 PR뿐인 것을 체크리스트에 올린다. 입력 "미룬 일: …(이 PR 본문에 기록)"이면 이슈가 만들어진다. 프롬프트 입력은 PR 본문이라 STATUS에 실제로 적혔는지는 확인하지 않는다
- 훅과 감사 항목은 더하지 않는다. PR 본문은 감사 시점에 없고, 건수가 적다(구분을 쓴 ADR-0077 뒤 두 건)
- gen-exp.md: 기준 judge를 DECISIONS 머리 줄로 가리키고, 실패 처리를 D-64로, 지시 변경을 동결 예외 조건(P1, D-63 결정 10)으로 맞춘다
- protocol-guard P11, pr-briefer R7: 대상을 `j_v8` 파일 하나가 아니라 동결 테스트가 해시를 고정한 지시 파일로 적는다. protocol-guard description은 바꾸지 않는다(j_v8이 동결 대상인 것은 그대로 맞고 본문 P11이 범위를 정한다)

## 결과

`.claude/rules/git.md`(PR 절 3), `.github/prompts/daily-pr-digest.md`(모을 것 5), `.claude/skills/meet-rag/references/gen-exp.md`, `.claude/skills/protocol-guard/SKILL.md`(P11), `.claude/agents/pr-briefer.md`(R7)에 반영했다. `src/rag/gen_eval/judge.py`의 안내 문구도 특정 버전을 적지 않게 고쳤다. PR #190의 `exp019.yaml:7` 항목은 `docs/PLAN.md` 평가 쪽 아이디어로 옮겼다.

일일 종합에 미룬 일 확인 항목이 늘 수 있다. 기록처를 STATUS·PLAN에 적으면 올라오지 않는다.

## 삭제 조건

이 항목이 일일 종합에 올라오지 않는 상태가 이어지거나, 일일 종합을 쓰지 않게 되면 지운다. 같은 빠짐이 반복되면 그때 PR 전 단계의 확인을 검토한다.
