# ADR-0067 protocol-guard의 "SPEC 개정 전/뒤" test 조건을 정리

- 상태: 채택
- 날짜: 2026-10-27

## 맥락

protocol-guard P1·P6은 생성 단계 test 1회를 "생성 평가 SPEC 개정 뒤"에만 허용하고, P6은 그 1회의 외부 전송을 CLAUDE.md 금지 절 외부 전송 줄이 고쳐진 뒤로 미뤘다(ADR-0051). SPEC 개정은 D-53으로 끝났고, 외부 전송 줄은 같은 PR(SPEC 개정 뒤 안내문 정리, D-53 남은 일)에서 단계마다 1회로 고친다. 조건이 채워졌는데 문구가 남으면 감사가 이미 끝난 개정을 기다리는 조건으로 읽는다.

## 결정

- P1: 생성 단계 1회는 생성 단계를 마칠 때 사용자 지시로 한다고 적고, "SPEC 개정 전" 단서와 위반 항목의 "SPEC 개정 전 생성 단계 test 실행"을 지운다. 드라이런은 "사용자 지시 기록 없는 실행"에 넣어 계속 위반으로 본다
- P1(PR #166 리뷰, 사용자 결정 2026-10-27): 지시를 받은 1회 안에서 본 실행 전에 하는 드라이런은 같은 1회로 본다. 1회 제한이 막는 것은 결과를 보고 점수를 올리려는 변경이고 실행 여부 확인은 막지 않는다. 드라이런 결과로 설정·코드를 바꾸면 두 번째 실행으로 보고, 실행 오류 수정은 해당하지 않는다(메인 해석)
- P1(같은 리뷰, 사용자 설명): 생성 단계를 마치는 때는 사용자가 정한다. 백로그 실험을 우선순위대로 진행하고 남은 실험의 예상 개선 폭이 작으면 닫고 마친다. 검색 단계(S13)와 같다
- P6: 생성 단계 1회의 외부 전송(OpenRouter 생성, opencode Go judge)은 허용된다고 적는다. Colab 업로드는 새 ADR이 필요하다는 문장은 그대로다

## 결과

`.claude/skills/protocol-guard/SKILL.md`(P1, P6). pr-briefer R6은 이미 단계별 1회라 고치지 않았다. 단계별 1회 원칙(ADR-0051)은 그대로다.

## 삭제 조건

SPEC의 test 사용 규칙이나 CLAUDE.md 금지 절의 test 줄이 바뀌면 함께 고친다.
