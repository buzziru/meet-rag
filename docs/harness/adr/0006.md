# ADR-0006 Colab 보조 스크립트 `colab_job.py`

- 상태: 일부 대체(→ 0010)
- 날짜: 2026-10-01
- 커밋: ff12574, d5bfe53

## 맥락

S4 Colab 실행 두 번에서 같은 함정이 반복됐다: Git Bash의 `/content` 경로 변환, cp949 출력 오류, push하지 않은 커밋 체크아웃 실패, config override 오타, Colab 기본 Python 3.13과 `requires-python ==3.12` 충돌, 20분 전후의 연결 끊김, tar의 `C:` 해석. `colab-operator` 스킬도 불러오지 않고 기억으로 진행했다.

## 결정

VM 조작을 `scripts/colab_job.py`(preflight, `uv sync --extra cu126`로 환경을 맞추는 setup, upload, VM 안 nohup으로 띄우는 launch, poll, fetch, finish)로 한다. E절에 VM 할당 전 `colab-operator`를 불러오는 단계와, 확인된 요율로 compute unit을 예상하는 규칙을 넣는다. upload·fetch는 저장소 안 경로로 제한한다. 평가 질의는 VM에 올리지 않고 로컬에서 임베딩한다(`upload`가 `queries_*`·분할 파일을 막는다).

## 결과

`.claude/skills/meet-rag/scripts/colab_job.py`, E절. S5 질의 임베딩(T4)에서 VM 쪽 명령을 처음 썼고 그대로 동작했다. 질의 업로드 금지는 ADR-0010이 dev 질의 허용으로 바꿨다.

## 삭제 조건

colab CLI가 위 함정을 스스로 해결하거나, GPU 실행 환경이 Colab이 아니게 될 때.
