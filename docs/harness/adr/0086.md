# ADR-0086 허용 처리처 목록을 CLAUDE.md 한 곳에 두고 P6은 그곳을 읽음, test 추적 끄기 보고

- 상태: 채택
- 날짜: 2026-11-04

## 맥락

D-72가 LangSmith를 허용 처리처에 더하고 test 1회 실행은 추적을 끄기로 정했다. 처리처 목록이 `CLAUDE.md`, SPEC, `protocol-guard` P6 세 곳에 있어 하나라도 빠지면 감사가 지금 규칙과 다르게 판정한다.

## 결정

P6에서 처리처 이름을 지우고 `CLAUDE.md` 금지 절의 줄을 읽어 대조하게 한다(지금 기준을 한 곳에 두는 ADR-0076과 같은 이유). test 1회 실행 명령이나 절차에 `LANGSMITH_TRACING=false`가 없으면 보고하게 한다. 실행을 막는 훅은 두지 않는다. test 1회는 사용자 지시로만 하는 일이다.

## 결과

`.claude/skills/protocol-guard/SKILL.md`에 반영했다.

## 삭제 조건

D-72를 바꾸면 함께 고친다.
