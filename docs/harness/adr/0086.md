# ADR-0086 protocol-guard P6에 LangSmith 처리처와 test 추적 끄기를 넣음

- 상태: 채택
- 날짜: 2026-11-04

## 맥락

D-72가 LangSmith를 허용 처리처에 더하고 test 1회 실행은 추적을 끄기로 정했다. `protocol-guard` P6의 처리처 목록이 그대로면 감사가 지금 규칙과 다르게 판정한다.

## 결정

P6 목록에 LangSmith를 더하고, test 1회 실행 명령이나 절차에 `LANGSMITH_TRACING=false`가 없으면 보고하게 한다. 실행을 막는 훅은 두지 않는다. test 1회는 사용자 지시로만 하는 일이다.

## 결과

`.claude/skills/protocol-guard/SKILL.md`에 반영했다.

## 삭제 조건

D-72를 바꾸면 함께 고친다.
