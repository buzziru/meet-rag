# ADR-0082 판정 하네스에 잘못 귀속 안전 조건을 넣음

- 상태: 채택
- 날짜: 2026-11-03

## 맥락

D-68이 생성 판정에 잘못 귀속 안전 조건을 더했다. `exp-judgment`의 판정 표와 보고 목록이 옛 조건만 적으면, 판정 보고에서 이 조건과 화자 이름이 나온 답변 수가 빠진다.

## 결정

`exp-judgment` 스킬의 판정 표, 걸린 조건 목록, 보고할 값에 발언자 불일치 비율을 더하고, 화자 이름이 나온 답변 수를 함께 적게 한다. 기준값은 스킬에 적지 않고 SPEC과 `configs/eval/gen_v1.yaml`을 따른다.

## 결과

`.claude/skills/exp-judgment/SKILL.md`에 반영했다. `protocol-guard`와 에이전트 정의는 바꾸지 않는다. 판정 값은 `rag.gen_eval.compare`가 내고 스킬은 그것을 옮긴다.

## 삭제 조건

D-68 안전 조건을 없애면 함께 지운다.
