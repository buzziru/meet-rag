# ADR-0044 생성 평가 judge용 opencode Go를 허용 처리처에 더한다

- 상태: 채택
- 날짜: 2026-10-19

## 맥락

- 생성 평가 judge를 DeepSeek V4.1 Flash, opencode Go 구독 경로로 정했다(D-38, PR #99 코멘트). judge 입력에는 질의, 근거 문서, 참조 라벨이 들어간다
- D-31의 허용 처리처는 Google AI Studio, OpenRouter, Colab뿐이라, protocol-guard P6가 opencode Go 전송을 근거 없는 처리처로 볼 수 있었다

## 결정

- protocol-guard P6의 허용 외부 API에 "생성 평가 judge용 opencode Go(D-38)"를 더한다. CLAUDE.md 금지 절과 SPEC 자원 제약도 같이 고친다(사용자 지시 2026-10-19)
- `test` 질의 제한과 대량 전송 전 보고·승인은 그대로 둔다

## 결과

`.claude/skills/protocol-guard/SKILL.md`(P6), `CLAUDE.md`, `docs/SPEC.md`(자원 제약), `docs/DECISIONS.md`(D-38).

## 삭제 조건

- judge 경로를 opencode Go에서 다른 곳으로 바꾸면(이용 제한 등, D-38) 이 처리처를 목록에서 뺀다
