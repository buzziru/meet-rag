# ADR-0094 같은 지점으로 합류하는 조건부 단계는 그림의 분기로 세지 않는다

- 상태: 채택
- 날짜: 2026-11-05

## 맥락

PR #218 가이드가 켜면 도는 후처리 한 단계를 예/아니오 분기 두 개로 그렸다(사용자 피드백 2026-11-05). 코드에 조건은 있지만 모두 같은 지점으로 합류해 흐름은 일방향이다. 그림 조건 "분기 둘 이상"이 조건을 세는 것으로 읽혀 걸러 내지 못했다. 같은 유형의 앞선 지적은 일렬 흐름에 그린 그림이다(ADR-0033). 메인도 최종 가이드 요청에 직전 그림을 넘겼고 가이드가 그대로 통과시켰다.

## 결정

사용자 피드백대로 `pr-briefer`의 그림 조건을 좁힌다.

- 같은 지점으로 합류하는 조건부 단계는 분기로 세지 않는다. ADR-0033이 분기로 센 "건너뛰기" 경로 중 합류하는 것이 여기에 든다. 다른 처리나 종료로 갈라지는 분기가 둘 이상일 때만 그린다
- 입력→동작: "설정을 켜면 불릿 기호를 뗀다" 같은 단계만 더한 PR은 그림 없이 문장 하나로 쓴다
- 사용자 피드백의 "갈라지는 경로가 둘 이상"을 "분기 둘 이상"으로 읽었다. 분기 하나면 그리지 않는다는 ADR-0033이 그대로이기 때문이다. 입력→동작: 조건 하나로 통과→병합, 실패→중단으로 갈라지는 PR은 그리지 않는다
- 다시 부를 때 직전 가이드에 그림이 있어도 그리는 조건을 다시 따진다

## 결과

`.claude/agents/pr-briefer.md`에 반영했다. description의 "분기가 둘 이상"은 그대로라 트리거 검증은 하지 않는다. 실행 중인 세션에는 정의 수정이 바로 반영되지 않을 수 있다.

## 삭제 조건

리뷰 가이드에서 그림을 없애면 지운다.
