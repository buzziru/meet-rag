# ADR-0094 리뷰 가이드 그림은 조건에 따라 처리가 갈라질 때 그리고 일방향 흐름은 그리지 않는다

- 상태: 채택
- 날짜: 2026-11-05

## 맥락

PR #218 가이드가 켜면 도는 후처리 한 단계를 예/아니오 분기 두 개로 그렸다(사용자 피드백 2026-11-05). 코드에 조건은 있지만 모두 같은 지점으로 합류해 흐름은 일방향이다. 그림 조건 "분기 둘 이상"이 조건을 세는 것으로 읽혀 걸러 내지 못했다. 같은 유형의 앞선 지적은 일렬 흐름에 그린 그림이다(ADR-0033). 메인도 최종 가이드 요청에 직전 그림을 넘겼고 가이드가 그대로 통과시켰다.

PR #219 리뷰에서 사용자가 그림과 의사 코드의 목적을 설명했다(2026-11-05). 사용자는 에이전트가 쓴 코드를 일일이 살피지 않고, 어떤 로직으로 처리했는지 파악하려고 이 절을 둔다. a 조건에서 이렇게, b 조건에서 저렇게 다르게 처리했다면 그것을 그림과 의사 코드로 표시해 인지 부담을 줄이고, 일방향 파이프라인은 비교적 파악이 쉬워 그림이 필요 없다. 메인은 처음에 "갈라지는 경로가 둘 이상"을 "분기 둘 이상"으로 읽어 조건 하나로 갈라지는 PR을 빼려 했고, 이 설명으로 바로잡았다.

## 결정

`pr-briefer`의 그림 조건을 분기 개수가 아니라 조건에 따라 처리가 달라지는지로 정한다. ADR-0033의 "분기가 없거나 하나뿐이면 절을 뺀다"와 건너뛰기 경로를 분기로 세는 부분을 대체한다.

- 조건에 따라 처리가 달라지면 조건이 하나여도 그린다. 입력→동작: 조건 하나로 통과→병합, 실패→중단으로 갈라지는 PR은 그린다
- 한 단계를 더 돌거나 건너뛰기만 하는 조건부 단계는 어느 쪽이든 다음 단계가 같아 일방향으로 보고 그리지 않는다. 입력→동작: "설정을 켜면 불릿 기호를 뗀다" 같은 단계만 더한 PR은 그림 없이 문장 하나로 쓴다
- 의사 코드도 목적이 같으므로 조건 세부에 더해 조건별 처리가 문장으로 옮기기 어려울 때 쓴다
- 다시 부를 때 직전 가이드에 그림이 있어도 그리는 조건을 다시 따진다

## 결과

`.claude/agents/pr-briefer.md`의 description, 구조 절, 다시 호출 절에 반영했다. 실행 중인 세션에는 정의 수정이 바로 반영되지 않을 수 있다.

## 삭제 조건

리뷰 가이드에서 그림과 의사 코드를 없애면 지운다.
