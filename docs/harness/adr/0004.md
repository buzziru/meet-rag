# ADR-0004 Colab 비용 변동과 예상 밖 재할당, 실행 기록 위치

- 상태: 채택
- 날짜: 2026-10-01
- 커밋: 9714c78

## 맥락

PR #11 사용자 코멘트. 할당 GPU가 바뀌거나 비용이 예상과 다를 때 멈출지, VM이 회수됐을 때 다시 할당할지가 정해져 있지 않았다.

## 결정

비용이 예상과 달라졌다는 이유만으로 작업을 멈추지 않는다. T4 대체는 승인 범위 안이라 알리기만 한다. VM 회수(404·401) 등 승인 때 예상하지 않은 GPU 사용이 생기면 새 VM을 만들기 전에 상태를 확인하고 보고하며, 재할당은 사용자가 정한다. Colab 실행 기록(`*_output.ipynb`, `colab log -o`)은 `outputs/notebooks/`에 둔다. 노트북 출력에 질의가 조금 들어가는 것은 허용한다(P5).

## 결과

`.claude/skills/meet-rag` E절·오류 처리 절, `protocol-guard` P5.

## 삭제 조건

Colab 과금 방식이 정액이 되거나 GPU 실행 환경이 바뀔 때.
