# ADR-0072 judge 형식 재요청을 동결 감사(P11)와 생성 EXP 절차에 반영

- 상태: 채택
- 날짜: 2026-10-28

## 맥락

S28에서 judge 형식 재요청(D-58·D-59)을 구현했다. 교정 지시와 상한은 j_v8 밖 새 파일 `configs/judge/format_retry/fr_v1.yaml`에 두고 동결 대상으로 삼기로 했다(D-58 결정 6). 동결 테스트(`tests/test_gen_eval_freeze.py`)는 SLICE 코드에서 더했지만, PR 감사의 동결 목록(protocol-guard P11)에 이 파일이 없으면 테스트 기대값과 함께 고친 diff를 감사가 위반으로 보지 않는다. 생성 EXP 절차(`references/gen-exp.md`)는 재요청 구현 전 상태(기준 결과 경로 미정, JSON으로 읽을 수 없는 응답만 재요청)로 적혀 있었다.

## 결정

- protocol-guard P11 위반 목록에 `configs/judge/format_retry/fr_v1.yaml`과 동결 테스트의 judge 요청 본문 sha256 기대값(리뷰 G1-3)을 더한다
- 요청 본문 sha256은 judge 실행 설정도 담는다. 실행 설정은 평가자를 정하는 값이고(PR #167 리뷰: 멈춤은 평가자 동일성을 보려는 것, 용인은 생성 쪽 값만), 사용자 결정과 DECISIONS로 평가자를 바꾼 PR이 기대값을 맞춰 고친 것은 위반이 아니라고 P11 첫 항목에 적는다. 적지 않으면 같은 diff에 P11 두 항목이 다른 답을 낸다(PR #176 리뷰, 사용자 승인 2026-10-28)
- `references/gen-exp.md`의 기준 실험을 재채점 결과 `…-j_v8-n330-fr_v1.jsonl`로 적고, "형식 오류율"의 재요청 범위를 P6 형식 오류 전체·상한 1회로, 남은 형식 오류와 재요청 수를 읽는 report 칸을 적는다

## 결과

`.claude/skills/protocol-guard/SKILL.md`(P11 한 줄), `.claude/skills/meet-rag/references/gen-exp.md`(기준 실험, 형식 오류율). description은 바꾸지 않았다.

## 삭제 조건

judge 형식 재요청을 없애거나 구조화된 응답으로 바꾸면 P11의 해당 항목과 함께 지운다.
