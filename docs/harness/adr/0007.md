# ADR-0007 `_workspace/` 작업 기록과 하네스 개선 대기 목록

- 상태: 채택
- 날짜: 2026-10-01
- 커밋: ff12574

## 맥락

서브에이전트는 매번 새로 떠서 이전 맥락을 모르고, 메인의 맥락도 세션이 바뀌면 사라진다. 사용자는 진행 상황을 파일로 보고 싶어 했다.

## 결정

`_workspace/`를 로컬 전용(`.gitignore`) 작업 디렉터리로 둔다. 흐름마다 `{작업}_{작성자}_{내용}.md` 진행 기록을 남기고 단계마다 갱신하며, 에이전트 프롬프트에 경로를 넣는다. 작업 중 발견한 하네스 개선 거리는 `00_main_harness-pending.md`에 적어 두었다가 `chore/` 브랜치에서 반영한다. 최종 결과와 결정은 여기 두지 않는다.

## 결과

`.claude/skills/meet-rag` "작업 기록" 절, `.gitignore`.

## 삭제 조건

세션 간 맥락을 다른 수단(하네스 상태 파일, 이슈 트래커 등)이 대신할 때.
