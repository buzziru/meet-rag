# ADR-0099 화면 검증의 대상 주소를 Vercel 배포 페이지로 한정한다

- 상태: 채택
- 날짜: 2026-11-05

## 맥락

`meet-rag` 스킬 "화면 검증" 절은 대상을 로컬 개발 주소나 우리 Space로 정했다(ADR-0089). D-88 결정 1은 사용자 확인과 Aside의 화면 점검을 모두 Vercel 배포 페이지에서 하기로 했고, 절의 고침은 하네스 PR로 넘겼다.

## 결정

대상을 Vercel 배포 페이지만으로 고친다. 토큰 스크립트와 Space 로그로 하는 값 확인은 브라우저 점검이 아니므로 이 절의 대상이 아니고 그대로 Space를 부른다(D-88 결정 1). 실행마다 대상 주소 하나를 넘기고 규칙에 주소를 박지 않는 ADR-0089의 방식은 그대로 둔다.

감수하는 것: Vercel 미리보기 배포를 꺼 두어(D-88) 페이지 코드 변경은 `main` 병합 뒤에야 Aside로 볼 수 있다.

## 결과

`.claude/skills/meet-rag/SKILL.md` "화면 검증" 절의 대상 주소 항목을 고쳤다. 입력→동작: S45 답변 표시 점검은 Vercel 배포 주소를 넘기고, Space 응답 값 확인은 Aside 없이 토큰 스크립트로 한다.

## 삭제 조건

화면 점검을 다른 페이지에서 하기로 결정하면 새 ADR로 바꾼다.
