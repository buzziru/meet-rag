# ADR-0051 감사 기준의 test 1회를 단계별 종료 측정으로 적음

- 상태: 채택
- 날짜: 2026-10-20

## 맥락

- protocol-guard P1·P6과 pr-briefer R6은 test를 "검색 단계 종료 시 1회만" 허용한다고 적었다. CLAUDE.md 금지 절의 test 줄과 PLAN(D-38, PR #102 코멘트)은 생성 단계 종료 1회도 허용한다(SPEC 개정 뒤). CLAUDE.md 외부 전송 줄과 SPEC 본문은 아직 검색 단계 1회만 적는다. 그래서 감사가 생성 단계 test 준비나 남겨 둔 test 경로를 반복해서 위반으로 지적했다(사용자 지적 2026-10-20)
- 사용자 의도(2026-10-20): 검색과 생성 단계를 마칠 때마다 test로 점수를 1회만 잰다. 목적은 test로 결정을 조정하지 않는 것이다. 생성 단계에서 검색을 고칠 수 있고, 생성 단계 평가를 test로 하면 검색도 test로 돌린다. 그래서 검색 단계 측정 뒤에도 test 경로를 지우지 않았다
- SPEC 본문(분할 표, 누수 방지, 자원 제약)은 아직 검색 단계 1회만 적고 있다. 생성 단계 1회는 생성 평가 초안(`docs/drafts/spec-generation-eval.md`)을 SPEC에 옮길 때 반영된다

## 결정

- P1에 단계별 종료 측정 1회를 예외로 적는다. 목적은 test로 설정·결정을 조정하지 않는 것(P2)이고, 1회 밖의 읽기·채점은 조정 여부와 관계없이 위반이다. 생성 단계 1회에는 test 질의로 검색을 다시 돌리는 것을 포함한다. 남겨 둔 test 경로와 test를 실행하지 않는 준비는 위반이 아니고, 지시 기록 없는 실행, 같은 단계의 두 번째 실행, SPEC 개정 전 생성 단계 실행은 위반이다
- P6은 P1을 참조하되, 생성 단계 1회의 외부 전송은 CLAUDE.md 외부 전송 줄이 고쳐진 뒤에, Colab 전송은 업로드 허용 ADR을 다시 둔 뒤에 허용한다. R6은 P1을 참조한다
- 이 변경의 PR 전 감사가 P6이 CLAUDE.md 외부 전송 줄보다 넓다고 지적해 위 조건을 더했다

## 결과

`.claude/skills/protocol-guard/SKILL.md`(P1, P6), `.claude/agents/pr-briefer.md`(R6), `.claude/skills/meet-rag/SKILL.md`(E절의 test Colab 처리 조건), `docs/drafts/spec-generation-eval.md`(SPEC으로 옮길 때 고칠 곳).

## 삭제 조건

- 생성 평가 SPEC 개정과 CLAUDE.md 외부 전송 줄 수정이 끝나면 P1·P6의 "SPEC 개정 전/뒤" 조건을 지운다
