# ADR-0092 Git Bash에서 hf 인자의 /경로 변환을 끈다

- 상태: 채택
- 날짜: 2026-11-05

## 맥락

S38에서 Git Bash가 Space 변수 `HF_HOME`의 값 `/tmp/hf-home`을 Windows 경로로 바꿔 넣었다. 모델이 `/app` 아래에 받아진 것을 검증에서야 찾았다(`docs/slices/38-hf-space.md` 결과 절). 1회 사례지만 측정 뒤에야 드러났고, 막는 데 드는 것은 문장 하나다.

## 결정

`meet-rag` "Hugging Face 작업" 절에 Linux 쪽에서 쓸 `/` 경로를 넘길 때 `MSYS_NO_PATHCONV=1`을 붙이라고 적는다. 로컬 파일 경로는 변환이 필요할 수 있어 대상에서 뺀다(실행해 확인하지는 않았다). 훅은 두지 않는다.

## 결과

`.claude/skills/meet-rag/SKILL.md`에 반영했다.

## 삭제 조건

`hf` 명령을 Git Bash에서 부르지 않게 되면 지운다.
