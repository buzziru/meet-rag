# ADR-0092 Git Bash에서 hf 인자의 /경로 변환을 끈다

- 상태: 채택
- 날짜: 2026-11-05

## 맥락

S38에서 Git Bash가 Space 변수 `HF_HOME`의 값 `/tmp/hf-home`을 Windows 경로로 바꿔 넣었다. 명령은 성공해 오류가 없었고, 모델이 `/app` 아래에 받아진 것을 검증에서 찾았다(`docs/slices/38-hf-space.md` 결과 절). 1회 사례지만 오류 없이 값이 바뀌어 나중에 찾기 어렵고, 막는 데 드는 것은 문장 하나다.

## 결정

`meet-rag` "Hugging Face 작업" 절에 `/`로 시작하는 값을 넘길 때 `MSYS_NO_PATHCONV=1`을 붙이라고 적는다. 훅은 두지 않는다.

## 결과

`.claude/skills/meet-rag/SKILL.md`에 반영했다.

## 삭제 조건

`hf` 명령을 Git Bash에서 부르지 않게 되면 지운다.
