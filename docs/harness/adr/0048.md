# ADR-0048 노트북 §7.1의 예외 사례로 PR #96을 기록한다

- 상태: 채택
- 날짜: 2026-10-20

## 맥락

- 노트북 규약 §7.1은 `main`에 들어간 노트북의 셀·출력을 고치지 않는다고 정한다
- PR #93·#94로 들어온 노트북 세 개(31_02, 31_03, 32_01)가 `ruff check` 오류 31건을 내서 `main`의 린트가 실패했다. PR #96이 별도 브랜치에서 긴 줄을 줄바꿈하고, 32_01은 셀 안 중복 import 삭제와 변수 이름 변경(`l`→`line`)까지 했다. 사용자 지시는 "긴 줄만"이었고, 이 차이가 일일 종합 이슈 #112에 답 없는 판단할 곳으로 올라왔다

## 결정

- PR #96 전체(32_01의 import 삭제와 변수 이름 변경 포함)를 §7.1의 예외로 인정하고, 프로젝트에서 예외로 인정한 사례로 §7.1에 기록한다(사용자 결정 2026-10-20). 출력과 실행 기록은 그대로 두었으므로 근거 기록으로서의 노트북은 바뀌지 않았다

## 결과

- `.claude/rules/notebook.md` §7.1에 예외 기록 한 항목을 더한다

## 삭제 조건

- 없음. 예외 사례 기록이다
