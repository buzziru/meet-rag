# ADR-0059 문서 PR의 위험도 한 줄에 걸린 규칙만 적음

- 상태: 채택
- 날짜: 2026-10-26

## 맥락

`.claude/rules/git.md` PR 절 3은 `docs/` 아래만 바꾼 PR이 SPEC·DECISIONS를 바꾸거나 test 점수를 기록했을 때 본문 맨 위에 `위험도: 단방향(R1·R2·R6)` 한 줄을 적게 했다(ADR-0016). 문구가 고정이라, 걸린 규칙이 하나여도 셋을 모두 적었다. PR #141은 DECISIONS(D-47)만 바뀌어 R2만 걸렸는데 R1·R2·R6이 적혔고, 일일 종합 이슈 #142가 "R1과 R6에 걸리는 변경이 무엇인지 설명이 없다"고 물었다. 사용자는 걸린 규칙만 적게 고치기로 했다(사용자 결정 2026-10-26, 이슈 #142).

## 결정

- 괄호에는 걸린 규칙만 적고(SPEC R1, DECISIONS R2, test 점수 R6), 규칙마다 해당 변경을 짧게 붙인다. 예: `위험도: 단방향(R2: D-47 추가)`
- 이유: 위험도 한 줄은 사용자가 diff에서 무엇을 단방향으로 보고 읽을지를 알려 주는 것이다. 걸리지 않은 규칙이 적히면 사용자가 없는 변경을 찾게 되고, 규칙 번호만 있으면 어느 변경인지 다시 찾아야 한다. pr-briefer가 쓰는 가이드도 걸린 규칙과 그 `file:line`을 적는다

## 결과

`.claude/rules/git.md` PR 절 3. ADR-0016의 "메인이 위험도 한 줄을 적는다"는 그대로이고 적는 방식만 바뀐다.

## 삭제 조건

문서 PR에도 pr-briefer를 부르게 되어 위험도를 가이드가 쓰게 되면 이 한 줄 규칙과 함께 지운다.
