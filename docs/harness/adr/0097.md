# ADR-0097 세션 간 메시지는 입력 칸을 확인하고 메인이 직접 보낸다

- 상태: 채택
- 날짜: 2026-11-05

## 맥락

ADR-0085는 `orca terminal send`가 입력 칸에 끼어든다며 사용자가 요청할 때만 쓰게 했고, 전할 내용은 사용자에게 알리게 했다. 그러면 사용자가 세션 사이에서 말을 옮겨야 한다. 한편 실제로 메시지가 사용자가 쓰던 입력 뒤에 붙어 사용자가 입력을 취소한 일이 있어, 끼어듦 자체는 막아야 한다(사용자 지시 2026-11-05).

## 결정

사용자가 정했다(2026-11-05). 세션 간 메시지는 메인이 직접 보낸다. 보내기 전에 `orca terminal read --terminal <handle> --screen --json`으로 입력 칸과 `draft`가 비었는지 보고, 글자가 있으면 기다렸다 다시 보며, 보낸 뒤 도착을 확인한다. 기본 읽기는 지나간 출력을 쌓아 돌려주므로 지금 입력 칸을 보려면 `--screen`이 필요하다. Orca 작성 칸의 글은 화면 줄에 들어가지 않고 `draft`로만 나온다(둘 다 `orca terminal read --help`). 작성 칸의 글이 전송과 실제로 섞이는지는 시험하지 않았고, 사용자가 쓰던 글을 놓치지 않으려고 함께 본다.

ADR-0085의 나머지 규칙(`data/` 쓰기 전 확인, 공유 기록 경로)은 그대로다.

감수하는 것: 확인과 전송 사이에 사용자가 입력을 시작하면 섞일 수 있다.

## 결과

`.claude/rules/sessions.md`의 해당 줄을 바꿨다. 입력→동작: 입력 칸에 사용자가 쓰던 글자가 있으면 보내지 않고 기다렸다 다시 본다. 입력 칸이 비었으면 보내고 화면으로 도착을 확인한다.

## 삭제 조건

다른 세션과 병행하지 않게 되면 ADR-0085와 함께 지운다.
