# ADR-0085 사용자가 만든 다른 Orca 세션과 병행하는 규칙

- 상태: 채택
- 날짜: 2026-11-04

## 맥락

배포와 생성 실험을 다른 세션에서 병행하기로 했다(사용자 방침 2026-11-03). 하위 세션 지시에는 `data/` 규칙을 적지만(meet-rag "공유 `data/`와 위임"), 사용자가 + 버튼으로 만든 세션은 메인의 지시를 받지 않아 규칙을 전달할 경로가 없다.

## 결정

매 세션 읽히는 `.claude/rules/sessions.md`에 세 가지만 둔다. 쓰기 전에 `main`의 STATUS "실행 중 작업"을 보고, `_workspace/`는 메인 경로에서 읽고, `orca terminal send`는 요청받았을 때만 쓴다.

## 결과

`.claude/rules/sessions.md`를 새로 뒀다. 훅은 더하지 않는다. `data/` 삭제는 `data_delete_guard`가 이미 막는다.

## 삭제 조건

다른 세션과 병행하지 않게 되면 지운다.
