# ADR-0085 사용자가 만든 다른 Orca 세션과 병행하는 규칙

- 상태: 일부 대체(→ 0097, 0098)
- 날짜: 2026-11-04

## 맥락

배포와 생성 실험을 다른 세션에서 병행하기로 했다(사용자 방침 2026-11-03). 하위 세션 지시에는 `data/` 규칙을 적지만(meet-rag "공유 `data/`와 위임"), 사용자가 + 버튼으로 만든 세션은 메인의 지시를 받지 않아 규칙을 전달할 경로가 없다.

## 결정

매 세션 읽히는 `.claude/rules/sessions.md`에 세 가지만 둔다. 쓰기 전에 `main`의 STATUS "실행 중 작업"을 보되 이 칸은 핸드오프 때만 갱신되므로 다른 세션이 만든 파일은 묻고, 공유 기록은 메인 경로에서 읽고, `orca terminal send`는 요청받았을 때만 쓴다.

## 결과

`.claude/rules/sessions.md`를 새로 뒀다. 훅은 더하지 않는다. `data_delete_guard`는 worktree 세션의 `data/` 삭제에 확인을 띄운다. 메인 체크아웃의 삭제와 어느 세션의 덮어쓰기든 이 규칙에 맡긴다.

## 삭제 조건

다른 세션과 병행하지 않게 되면 지운다.
