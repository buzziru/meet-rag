# ADR-0063 노트북에는 줄 길이 검사와 ruff format을 적용하지 않음

- 상태: 채택
- 날짜: 2026-10-27

## 맥락

ADR-0060은 nb_kernel `run`이 실행 전에 `ruff check --fix`와 `ruff format`을 노트북에 적용하게 했고, 노트북 E501 완화는 정하지 않았다. main에 들어간 노트북 세 개가 ruff 오류 31건을 반복해 내서 고친 일이 있었는데, 고친 내용은 긴 줄 줄바꿈, 중복 import 삭제, 변수 이름 하나였다(노트북 규약 §7.1의 PR #96 예외 기록). `ruff format`은 100자를 넘는 식과 f-string 호출을 여러 줄로 나눈다.

사용자 판단(2026-10-27, 이슈 #156 3-11): 노트북을 쓰는 이유는 결정 근거를 남기는 것과 사람이 과정을 리뷰·회고하는 것이다. 기계적 줄 나눔은 둘째 목적의 가독성을 낮춘다. 줄 길이는 노트북을 검사에서 빼고 노트북 작성 규약으로 대신한다.

## 결정

- `pyproject.toml`: 노트북(`notebooks/**/*.ipynb`)은 E501을 검사하지 않고(`per-file-ignores`), `ruff format` 대상에서 뺀다(`[tool.ruff.format] exclude`). 나머지 ruff 규칙(F, I 등)은 그대로 적용한다
- `nb_kernel.py run`: `ruff format`을 빼고 `ruff check --fix`만 적용한다
- 노트북 규약 §2.3: 한 줄에 논리 하나, 긴 식은 이름 붙인 중간 변수로, 출력용 문자열과 표 머리글은 나누지 않음, 인자가 많은 호출은 인자마다 한 줄

## 결과

`pyproject.toml`, `.claude/skills/meet-rag/scripts/nb_kernel.py`·`test_nb_kernel.py`, `.claude/rules/notebook.md`. ADR-0060의 `ruff format` 적용 항목은 이 ADR로 대체된다. `main`에 들어간 노트북은 고치지 않는다(규약 §7.1).

## 삭제 조건

규약만으로는 읽기 어려운 노트북이 반복되면(리뷰에서 줄 길이 지적이 다시 나오면) 노트북용 줄 길이 상한을 따로 두는 방안을 새 ADR로 정한다.
