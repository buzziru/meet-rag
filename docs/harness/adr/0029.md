# ADR-0029 판정 하네스에 메타데이터 가설의 multi-doc 판정과 가설 단위 중단을 반영

- 상태: 채택
- 날짜: 2026-10-08

## 맥락

D-18(PR #47)에서 SPEC을 고쳤다. 메타데이터 가설은 single-doc 보류일 때 multi-doc(Recall@5 개선, Complete@5 비하락)으로 판정하고, 비채택 3회 연속 중단은 한 백로그 항목 안의 변형에만 적용한다(사용자, PR #47 코멘트: 하나의 가설은 한 백로그 항목 안의 파라미터 변경 같은 변형). 하네스는 옛 규칙을 그대로 적고 있었다. `exp-judgment` 3절 표는 single-doc 규칙만 있었고 2절은 "multi-doc은 판정에 쓰지 않는다"였다. meet-rag B6은 서로 다른 가설의 비채택 3회 연속을 중단으로 알렸다. 그대로 두면 EXP-002(H5 BM25 변형)를 옛 규칙으로 판정한다.

## 결정

- `exp-judgment` 3절에 메타데이터 가설의 판정 표를 더하고, 표는 SPEC의 요약이라 다르면 SPEC을 따른다고 적었다. 같은 규칙을 두 곳에 적으면 SPEC 개정 때 하네스 쪽이 옛 규칙으로 남는 일이 이번처럼 반복되므로, 원본이 SPEC임을 판정자에게 알린다. 결론에 판정이 정해진 단계와 multi-doc 채택 시 SPEC 단서를 적게 했다. EXPERIMENTS.md 한 줄 형식에 multi-doc 열을 더해 실제 파일(EXP-001)과 맞췄다
- `exp-judge`의 판정 기준에 "메타데이터 가설의 판정" 절을 넣고 SPEC 우선을 적었다
- meet-rag B1은 [메타데이터] 가설이면 해당 SPEC 절을 EXP 판정 기준에 옮기고, 같은 항목의 몇 번째 변형인지 적는다. B4는 judge에 multi-doc 순위 파일도 넘긴다. B6은 가설 단위 중단을 알린다

## 결과

`.claude/skills/exp-judgment/SKILL.md`, `.claude/agents/exp-judge.md`, `.claude/skills/meet-rag/SKILL.md` B1·B4·B6. description은 바꾸지 않았다.

## 삭제 조건

SPEC에서 메타데이터 가설의 판정 절이나 가설 단위 중단 기준을 없애거나 바꿀 때(그때 이 세 곳을 함께 고친다).
