# ADR-0035 Colab 작업은 시작을 확인한 뒤 백그라운드로 본다

- 상태: 채택
- 날짜: 2026-10-13

## 맥락

E6은 `launch` 뒤 `colab_job.py poll`로 로그를 보게만 적었고, 기다리는 방식은 정하지 않았다. 메인은 `poll`을 포그라운드로 돌려 VM 작업이 끝날 때까지 다른 일을 하지 못했다. EXP-006(KURE-Reranker-nano T4 채점) 실행 중 사용자가 실행을 확인했으면 백그라운드로 돌려 다음 작업을 하라고 지시하고, 하네스에 반영하도록 요청했다.

## 결정

E6에 다음을 더한다.

- 첫 `poll`에서 작업이 정상으로 시작된 것(모델 로드, 진행 표시가 오류 없이 나옴)을 확인하면 `poll`을 Bash `run_in_background`로 돌리고 메인은 다음 작업을 한다. 끝나면 알림이 온다
- dev-small 결과를 확인한 뒤 남은 단계는 `launch -- bash -c "명령1 && 명령2"`로 VM 작업 하나에 묶는다. dev-small과 dev-full을 처음부터 묶지 않는다(B3의 확인 순서)

시작 확인을 먼저 하는 이유는, 설정 오류나 경로 오류는 대개 시작 직후에 드러나고, 그 전에 다른 작업으로 넘어가면 실패를 늦게 알게 되기 때문이다.

## 결과

`.claude/skills/meet-rag/SKILL.md` E6.

## 삭제 조건

`colab_job.py`가 완료 알림을 자체로 보내게 되거나, Colab 작업을 다른 실행 방식(예약 작업 등)으로 옮길 때.
