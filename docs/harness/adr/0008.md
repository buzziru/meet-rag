# ADR-0008 검증의 로컬 CPU 임베딩은 판정에 필요한 최소 규모로

- 상태: 채택
- 날짜: 2026-10-01
- 커밋: ff12574, 1f0d177

## 맥락

S4 검증이 로컬 CPU 임베딩 두 번으로 약 20분 걸렸다. 로컬 CPU는 문서 20개·256 토큰에 약 6분이 걸려, 규모를 키워도 판정은 같고 시간만 는다.

## 결정

`slice-verifier`의 로컬 CPU 임베딩은 동작 확인에 필요한 최소 규모(예: 재개 확인은 문서 2\~3개와 작은 `index.shard_size`)로만 허용한다. 하네스 문서의 "노트북"은 Jupyter 노트북과 로컬 PC를 구분해 쓴다.

## 결과

`.claude/skills/meet-rag` A3, `slice-verifier`.

## 삭제 조건

로컬에 GPU가 생기거나 임베딩이 빨라져, 규모를 키워도 대기 시간이 문제가 되지 않을 때.
