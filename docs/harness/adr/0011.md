# ADR-0011 dev 평가 질의의 무료 쿼터 LLM 전송 허용

- 상태: 채택
- 날짜: 2026-10-02
- 커밋: bd9dcda, 03c050b

## 맥락

질의 노출을 조심하려던 "`summary_q`를 Google AI Studio 무료 쿼터로 보내지 않는다"가 의도보다 넓어, 데이터셋 질의로 생성 파이프라인을 개발할 수 없었다(사용자 판단, DECISIONS D-10).

## 결정

dev 질의는 무료 쿼터로 보낼 수 있다. `test` 질의는 검색 단계 종료 시 사용자 지시 1회 실행에서만 보낸다. 질의 전체처럼 많이 보내는 실행은 호출 수와 소요 시간을 보고하고 승인 후에 한다. `protocol-guard` P6을 "dev만 LLM 경로로"로, `slice-verifier`의 실행 금지 항목을 "허용된 질의 밖"으로 바꾼다.

## 결과

`protocol-guard` P6, `slice-verifier`, `protocol-auditor` 설명, CLAUDE.md 금지 절, SPEC, DECISIONS D-10, PLAN H8.

## 삭제 조건

생성 평가를 유료 경로로 완전히 옮기거나, 무료 쿼터 약관이 바뀌어 dev 질의 전송도 피해야 할 때.
