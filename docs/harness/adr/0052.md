# ADR-0052 질문 상자 wrap_up 앞에 본문 보고가 없으면 막는 훅

- 상태: 채택
- 날짜: 2026-10-20

## 맥락

- 결과·지시서를 본문으로 보고하지 않고 질문 상자(wrap_up `ask`)로 넘어가는 일이 반복됐다. 10-15(EXP-016 recap 보고), 10-19 2회(S14 지시서, 구현 결과), 10-20 3회(사고 과정 비교, 검수 집계, j_v3 재채점)에 사용자 지적이 있었다. 메모리(`report-work-in-chat`, `exp-report-full-metrics`)를 세 번 보강했지만 다음 날 다시 났다
- 사용자 판단(2026-10-20): Claude Code 업데이트 뒤 나타난 증상이고 그전 하네스에서는 문제가 없었으므로, 스킬에 보고 단계를 더하지 않는다
- 과거 세션 기록에서 질문 상자 wrap_up 직전 본문(마지막 사용자 메시지 뒤 어시스턴트 텍스트)이 400자 미만인 비율: 10-15 5/23, 10-19 22/38, 10-20 14/20(그중 11건은 0자). 400자 이상인 호출은 대부분 980자 이상이었다
- 이미 출력한 텍스트는 훅이 되돌릴 수 없다(ADR-0042). 막을 수 있는 시점은 wrap_up 호출 직전이다

## 결정

- PreToolUse 훅 `wrap_up_report_guard.py`를 `mcp__ccd_turn__wrap_up`에 단다. `ask`가 있을 때만 대화 기록을 읽고, 마지막 사용자 메시지(도구 결과·메타 메시지 제외) 뒤의 어시스턴트 텍스트가 400자 미만이면 호출을 막고 보고할 내용(만든 것, 결과 표, 해석, 어긋난 항목, 판단할 곳)을 돌려준다
- 스킬 흐름에는 보고 단계를 더하지 않는다. 하네스 훅 테스트를 `.claude/hooks/`에 두고 F 흐름의 하네스 테스트 명령에 더한다

## 결과

`.claude/hooks/wrap_up_report_guard.py`, `test_wrap_up_report_guard.py`, `.claude/settings.json`(PreToolUse), `.claude/skills/meet-rag/SKILL.md`(하네스 테스트 명령).

## 삭제 조건

- Claude Code 업데이트 뒤 훅을 빼고 확인했을 때 짧은 보고가 다시 늘지 않으면 지운다
- 짧은 답이 맞는 질문(단순 확인)에서 막힘이 잦아 사용자가 불편을 지적하면 기준을 낮추거나 지운다
