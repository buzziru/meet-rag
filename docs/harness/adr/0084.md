# ADR-0084 생성 EXP의 내용 판독은 gen-small로만 한다

- 상태: 채택
- 날짜: 2026-11-04

## 맥락

`gen-exp.md` B3은 작동 확인을 gen-small로 적었지만 근거·답변을 읽는 판독은 따로 적지 않았다. EXP-021에서 표지 판독에 gen-full 근거 30개를 넣었고, 사용자가 절차 위반으로 지적했다(2026-11-03). 그 질의들은 세트에 남기고 낙관 위험은 test 1회로 확인한다(D-70 결정 2).

## 결정

근거·답변을 읽는 확인도 gen-small 기록으로 하고, 판정 전에 gen-full 근거·답변을 표본으로 읽지 않는다. 코드로 세는 기계 대조는 내용을 읽지 않으므로 허용한다.

## 결과

`.claude/skills/meet-rag/references/gen-exp.md` B3에 반영했다. 감사로 잡을 수 없는 실행 중 행동이라 훅은 두지 않는다.

## 삭제 조건

생성 판정 세트를 나누는 방식(D-53)을 바꾸면 다시 본다.
