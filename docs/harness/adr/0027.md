# ADR-0027 Colab 업로드 검사가 G3 multi-doc 동결 세트 질의를 dev로 인정

- 상태: 채택
- 날짜: 2026-10-08

## 맥락

S9에서 G3 동결 세트 질의 600건(`md-` qid)을 Colab T4로 임베딩하기로 했다(사용자 결정). `colab_job.py upload`는 `qid`가 summary_q dev 분할(`data/splits/queries.csv`)에 있어야 통과시켜, 동결 세트 질의 파일이 dev 전용인데도 막혔다. 검사가 질의 세트를 하나만 알고 있었기 때문이다.

## 결정

`non_dev_qids`가 summary_q dev 분할의 `qid`와 함께 `data/multidoc/queries_g3.jsonl`의 `qid`를 dev 질의로 본다. 동결 세트는 SPEC "보조 관찰"에 따라 `test` 분할 회의를 뺀 문서로만 만들었고 D-15에서 고정됐다. 동결 세트에 없는 `md-` qid와 `test` 질의는 그대로 막힌다. 스킬 E6에 dev 질의의 범위를 적고, 스크립트 옆에 동작 테스트(`test_colab_job.py`)를 둔다.

## 결과

`colab_job.py`, `test_colab_job.py`, meet-rag 스킬 E6. S9 multi-doc 질의 임베딩을 Colab에서 할 수 있다.

## 삭제 조건

dev 질의 세트가 더 생기면(예: 새 multi-doc 세트) 목록을 config에서 읽게 바꾼다. 동결 세트를 쓰지 않게 되면 되돌린다.
