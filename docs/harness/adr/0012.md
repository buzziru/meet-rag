# ADR-0012 외부 API 5xx는 서버 상태부터 확인

- 상태: 채택
- 날짜: 2026-10-02
- 커밋: fe54814

## 맥락

S6 노트북 실행 중 Google AI Studio가 500 `INTERNAL`을 반복해 냈고, 서버 가용률이 80%대로 떨어진 상태였다(사용자가 OpenRouter 화면에서 확인). 그 사이 노트북을 처음부터 일곱 번 다시 실행했다. SDK도 5xx를 자동으로 두 번 다시 시도하므로 호출만 늘었다.

## 결정

5xx가 나면 다시 시도하기 전에 https://aistudio.google.com/status 에서 Google AI Studio·Gemini API 상태를 확인한다. 장애·성능 저하면 멈추고 보고하며, 정상일 때만 한 번 다시 시도한다. 402(결제)·403(인증)은 다시 시도하지 않는다.

## 결과

`.claude/skills/meet-rag` 오류 처리 절.

## 삭제 조건

생성 모델을 외부 API가 아닌 내부 서빙으로 바꿀 때.
