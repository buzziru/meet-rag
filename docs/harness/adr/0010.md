# ADR-0010 dev 질의는 Colab에서 임베딩 가능, 질의 데이터는 jsonl과 `qid` 키

- 상태: 채택
- 날짜: 2026-10-02
- 커밋: 8ad157c, fcb615f, 90a2f30

## 맥락

원래는 질의가 짧아 로컬 CPU로 충분하고 노트북으로 새어 나갈 수 있다는 이유로 평가 질의를 Colab에 올리지 않았다. 로컬 CPU 임베딩이 예상보다 오래 걸렸다(사용자 지시, DECISIONS D-07).

## 결정

dev 질의만 거른 파일은 Colab에 올릴 수 있고, `test` 질의와 분할 파일은 올리지 않는다. `colab_job.py upload`는 파일 이름과 무관하게 `.jsonl`에서 `qid`가 있는 행이 모두 dev 분할인지 확인한다. 이 검사가 형식에 기대므로 질의를 담은 데이터는 jsonl과 `qid` 키로 쓰고, `protocol-guard` P1이 이를 점검한다. 노트북에는 질의 원문을 대량 출력하지 않는다.

## 결과

`colab_job.py`, E6, `protocol-guard` P1, SPEC 자원 제약, DECISIONS D-07. S5 dev-full 질의 3,016건을 T4에서 임베딩했다.

## 삭제 조건

`test` 질의 임베딩도 VM에서 하기로 하거나, 질의 데이터 형식을 바꿀 때(검사도 함께 바꾼다).
