# ADR-0090 EXPERIMENTS.md의 역할, 읽는 때, 기록 규칙을 정한다

- 상태: 채택
- 날짜: 2026-11-04

## 맥락

`docs/EXPERIMENTS.md`는 쓰는 규칙만 있고 역할과 읽는 때가 정해져 있지 않았다. S42는 EXP 문서 없이 `configs/exp/exp024.yaml`로 기준 설정을 바꾸는데, 세션 마무리는 판정한 실험만 표에 적게 되어 있어 이런 config가 빠진다. 판정 칸 결정 번호 규칙과 "새 줄은 표 맨 위" 규칙은 2026-10-28(ce63169)에 생겼고, 그전 줄은 이 규칙과 어긋났다. 등재 누락 사례는 없었다.

## 결정

사용자가 수정안을 승인했다(2026-11-04).

- 역할: 실험별 판정 목록이다. 기준 설정의 원본은 DECISIONS, 판정 근거의 원본은 EXP 문서이고, 수치가 어긋나면 EXP 문서를 따른다
- 읽는 때: EXP 초안(앞 시험과 D-18 변형 횟수 확인), 다음 실험을 정할 때(PLAN 재정렬, 오차 분석 뒤 실험 추가 결정), 단계 종료 정합 점검과 단계 정리 문서
- 판정 칸 결정 번호는 결정이 있을 때 적는다. exp-judge는 번호를 알 수 없으므로 메인이 B6에서 붙인다
- 기준 설정을 바꾸는 EXP config는 판정 실험이 아니어도 한 줄을 쓴다
- 지난 문구 두 곳을 지금 규칙에 맞춘다(`exp-judgment` 생성 표 머리줄 안내, PLAN 결과 수치 문장)
- 검색 표를 번호 내림차순으로 정렬하고, 번호가 없던 줄에 찾은 결정 번호를 붙인다

protocol-guard 감사 항목은 더하지 않는다. 등재 누락 사례가 없었다.

## 결과

`docs/CLAUDE.md`(EXP 절), `CLAUDE.md`(문서 목록, 세션 마무리 2단계), `.claude/skills/meet-rag/SKILL.md`(B1, B6), `.claude/skills/exp-judgment/SKILL.md`, `docs/PLAN.md`, `docs/EXPERIMENTS.md`에 반영했다. 결정 번호를 붙인 줄은 001(D-17), 002(D-19), 003(D-23), 004(D-24), 005(D-25), 006(D-26), 008(D-27), 009(D-28), 015(D-33)이다. 007, 012, 013, 016은 해당 결정을 찾지 못해 비워 두었다. 판정·수치 칸은 바꾸지 않았다.

## 삭제 조건

EXPERIMENTS.md를 없애거나 판정 기록을 다른 곳으로 옮기면 지운다.
