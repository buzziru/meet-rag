# ADR-0043 test 1회 실행의 Colab 업로드 옵션

- 상태: 채택
- 날짜: 2026-10-19

## 맥락

- 검색 단계 종료 test 1회 실행(S13)은 리랭커 구성(EXP-017, D-36)으로 한다. test 후보 쌍(3,000여 질의 × 20쌍)을 채점하려면 GPU가 필요하고, 로컬 CPU로는 약 31시간이 걸린다(EXP-005 2스레드 기준 추정)
- 사용자가 채점 위치를 Colab T4 1회로 정했다(S13 결정 사항 2(a), 2026-10-19). D-31은 test 1회의 처리 위치를 그 실행 때 사용자 지시에 맡긴다
- `colab_job.py upload`는 dev가 아닌 qid가 있으면 업로드를 막아, 이 1회를 처리할 수 없다. 막는 장치를 손으로 우회하면(`colab upload`·`console` 직접 사용) 분할 파일·`.env` 검사도 함께 빠진다

## 결정

- `colab_job.py upload --allow-test`: dev·test 분할 qid를 통과시킨다. 어느 분할에도 없는 qid, 분할 파일(`queries.csv`), `.env`는 그대로 막는다. 옵션을 주면 허용 사실을 출력한다
- meet-rag E6과 오류 처리 시나리오, protocol-guard P6에 이 옵션이 S13 test 1회 전용임을 적는다. 다른 작업에서 쓰면 P6 위반이다
- 동작 테스트를 스크립트 옆에 둔다(`test_colab_job.py`)

넣지 않은 것: 1회 실행 횟수를 세는 장치. test 실행 횟수는 S13 절차와 실행 기록(해시)으로 지키는 안이고, 이 방식을 받아들일지는 PR #97에서 사용자가 판단한다(이 ADR 작성 시점에 미확정).

## 결과

`.claude/skills/meet-rag/scripts/colab_job.py`·`test_colab_job.py`, `.claude/skills/meet-rag/SKILL.md`(E6, 오류 시나리오), `.claude/skills/protocol-guard/SKILL.md`(P6).

## 삭제 조건

- S13 test 1회 실행이 끝나면 옵션의 쓸모가 없어진다. 남겨 두면 잘못 쓸 수 있으니, 실행 뒤 옵션과 이 서술을 지우는 것을 검토한다
