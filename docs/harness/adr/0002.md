# ADR-0002 작업 전환 때 0단계부터 다시, 지시서 확인 전 멈춤, 사람 검수 게이트(D 흐름)

- 상태: 채택
- 날짜: 2026-10-01
- 커밋: 32246d8, 11c1242

## 맥락

S1 뒤 같은 세션에서 S2·G1으로 넘어갈 때 스킬을 다시 읽지 않아 지시서 확인 단계가 빠졌다. PLAN의 G 항목(사람 검수)에는 대응하는 흐름이 없었다.

## 결정

새 조각·게이트·실험으로 넘어갈 때마다 스킬 0단계(브랜치, STATUS, 흐름 대응)부터 다시 한다. A1 지시서는 `docs: SLICE NN 지시서`로 구현과 따로 커밋하고, 사용자 확인 전에는 멈춘다. D 흐름(표본 도구 → 사용자 검수 → 집계 → 결정 지점 → 기록)을 추가하고, 규칙은 검색 점수를 보기 전에 정한다. STATUS "다음 행동"에 흐름 표기 `[A]`·`[B]`·`[C]`·`[D]`를 적는다. 스킬 description과 CLAUDE.md 호출 조건의 트리거를 넓혔다.

## 결과

`.claude/skills/meet-rag` 0단계·A1·D절, `protocol-auditor`, CLAUDE.md 호출 조건과 세션 마무리 절.

## 삭제 조건

스킬 호출이 훅 등으로 강제되어 작업 전환 때 단계를 건너뛸 수 없게 될 때. D 흐름은 PLAN에 G 항목이 더 없을 때.
