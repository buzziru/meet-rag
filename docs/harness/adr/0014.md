# ADR-0014 하네스 변경 이력을 ADR로 분리

- 상태: 채택
- 날짜: 2026-10-02
- 커밋: e9a9160

## 맥락

CLAUDE.md 하네스 절의 변경 이력 표가 행마다 여러 결정을 묶은 채 길어졌다. 매 세션 읽는 CLAUDE.md가 무거워지고, 어떤 규칙을 언제 없앨 수 있는지도 알 수 없었다(사용자 요청).

## 결정

하네스 변경은 `docs/harness/adr/NNNN.md`에 결정 하나씩 남긴다. 항목은 상태(채택, 일부 대체, 대체됨, 폐기)·맥락·결정·결과·삭제 조건이다. CLAUDE.md에는 하네스 목표·호출 조건과 ADR 목록 링크만 둔다. 기존 변경 이력 8행은 결정 단위로 나눠 ADR-0001\~0011로 옮겼다.

## 결과

`docs/harness/adr/`, CLAUDE.md 하네스 절, `.claude/skills/meet-rag` "작업 기록" 절. `harness:evolve`로 하네스를 고칠 때 CLAUDE.md 표 대신 ADR을 추가한다.

## 삭제 조건

하네스를 다른 구조로 다시 만들어 이력 관리 방식을 새로 정할 때.
