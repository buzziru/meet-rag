# ADR-0055 커밋 타입을 훅으로 막고, Bash로 고친 파일의 손상을 실행 직후 알림

- 상태: 채택
- 날짜: 2026-10-21

## 맥락

규칙 문서가 있는데도 같은 실수가 다시 나고, 사후에 고치는 일이 반복됐다(사용자 지적 2026-10-21).

- 커밋 타입: `.claude/rules/git.md` 커밋 절에 허용 타입이 있지만 커밋할 때 대조하는 단계가 없다. 규약에 없는 `perf`로 커밋한 일이 사용자 기억으로 두 번 있었다(S16의 것은 올리기 전 amend로 고쳐 이력에 없음)
- 파일 손상: 스킬 오류 처리 절(ADR-0053)이 "이스케이프가 든 문자열은 heredoc 안 Python이 아니라 Edit 도구로" 정했지만, S17에서 테스트 함수를 통째로 덧붙이는 스크립트를 이 규칙의 대상으로 보지 않아 `\n`이 실제 줄바꿈으로 들어가 테스트 파일이 깨졌다(누적 4회). S16에서는 스크립트의 `Path.write_text`가 Windows에서 CRLF로 써서 파일 두 개의 줄바꿈이 바뀌었다. 둘 다 ruff나 git 경고를 우연히 볼 때까지 몰랐다

이스케이프가 든 heredoc 명령을 실행 전에 막으면 정상 명령까지 막힌다. 이번 세션의 스크립트 대부분이 `f.write(json.dumps(r) + "\n")`처럼 `\n`을 정상으로 썼다. 오탐으로 작업이 늦어지면 훅을 끄게 된다(사용자 의견 2026-10-21).

## 결정

- `commit_type_guard`(PreToolUse, `if: "Bash(git commit *)"`): `-m`/`--message`로 준 첫 줄의 `<타입>:`이 허용 목록 밖이면 막고 허용 목록을 알린다. 메시지를 명령에서 찾지 못하면(`-F`, `--amend --no-edit`) 보지 않는다
- `file_damage_check`(PostToolUse): 막지 않는다. `python`·`sed -i`가 든 Bash 명령 뒤에 작업트리의 바뀐 파일을 보고, `.py` 구문 오류와 CRLF(`.gitattributes`가 작업트리까지 LF로 정함)가 있으면 exit 2로 알린다. 이진 파일은 건너뛴다
- 훅 띄우는 조건은 `if`로 건다. Windows에서 훅 하나에 약 0.5초(uv Python 시작 약 0.4초, venv Python도 0.4초 안팎)가 들어 모든 Bash 뒤에 띄우면 그만큼 늦어진다. `if: "Bash(*<<*)"`는 heredoc 명령에 걸리지 않아 쓰지 않는다. 깨진 사례는 모두 heredoc으로 만든 Python 스크립트였고 `python` 조건에 걸린다. `if`를 지원하지 않는 버전에 대비해 스크립트 안에서도 같은 조건으로 거른다
- 이스케이프하지 않은 `~`는 보지 않는다. Write·Edit로 바꾼 `.md`는 사용자 전역 훅(`ko-doc-check.py`)이 보고, Bash로 `~`가 깨진 사례는 없다
- 스킬 오류 처리 절과 `git.md` 커밋 절에 훅을 적었다. 오류 처리 절은 "함수·테스트를 통째로 덧붙이는 스크립트도 같다", "스크립트로 쓸 때 `newline=\"\n\"`"로 넓혔다

검증: 훅 테스트(`.claude/hooks/test_commit_type_guard.py`, `test_file_damage_check.py`)에 이번 세션의 실제 명령을 넣었다. 막을 것: `perf:`, 타입 없는 메시지, 깨진 `.py`, CRLF. 통과할 것: 허용 타입 5형태(heredoc 메시지, `--amend`, `-qm` 포함), 정상 `\n`이 든 스크립트, 이진 파일. 이 세션에서 실제로 실행해 `perf:` 드라이런이 막히고, 깨진 임시 파일이 `PYTHONUTF8=1 uv run python`과 `sed -i` 뒤에 알려지고, `git status`와 heredoc `cat` 뒤에는 훅이 뜨지 않는 것을 확인했다.

## 결과

`.claude/hooks/commit_type_guard.py`, `.claude/hooks/file_damage_check.py`와 각 테스트, `.claude/settings.json`, `.claude/skills/meet-rag/SKILL.md`(오류 처리), `.claude/rules/git.md`(커밋 절). `python` 명령마다 약 0.5초가 더해진다.

## 삭제 조건

- `commit_type_guard`: 커밋을 Claude가 하지 않게 되거나, 저장소에 같은 검사를 하는 git `commit-msg` 훅·CI를 두면 지운다
- `file_damage_check`: 몇 주 동안 알림이 한 번도 오지 않고 같은 손상도 없으면 지운다. 오탐 알림이 반복되면 조건을 좁히고, 줄지 않으면 지운다
