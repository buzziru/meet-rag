# ADR-0083 LangSmith 추적은 실행 명령 앞에 붙인 값으로 정한다

- 상태: 채택
- 날짜: 2026-11-04

## 맥락

D-71이 추적을 단건·gen-small·배포에서 켜고 gen-full·반복 측정에서 끄기로 정했는데, `gen-exp.md` B3은 gen-small까지 끄게 적혀 있었고 `CLAUDE.md`의 실행 줄에는 값이 없었다. 사용자가 Doppler를 고쳐 `doppler run` 안에 값이 없고 앞에 붙인 값이 그대로 전달된다(2026-11-04 확인). 그래서 값을 붙이지 않으면 추적을 켜는 값이 전달되지 않는다.

## 결정

`gen-exp.md` B3과 `CLAUDE.md`의 `rag.*` 실행 줄에 켜고 끄는 값을 명령 앞에 붙이도록 적는다. 값은 D-71을 따르고, 월 한도 초과가 다시 나면 끈다. 코드와 config에는 두지 않는다.

## 결과

`.claude/skills/meet-rag/references/gen-exp.md`, `CLAUDE.md`에 반영했다. 배포 환경의 설정은 배포 조각에서 정한다.

## 삭제 조건

D-71을 바꾸거나 LangSmith 추적을 없애면 함께 고친다.
