# ADR-0013 노트북은 지속 커널에서 실패 셀부터 이어 실행

- 상태: 채택
- 날짜: 2026-10-02
- 커밋: fe54814

## 맥락

Claude는 `nbclient`로 노트북을 실행해 왔다. 이 방식은 실행마다 커널을 새로 띄우므로, 셀 하나가 실패해도 처음부터 다시 돌려야 했다. API 호출 셀이 있는 S6 노트북에서 호출이 반복됐다.

## 결정

`scripts/nb_kernel.py`로 커널을 백그라운드에 띄워 두고(`start`), 셀을 하나씩 실행하며(`run --from N`), 셀마다 출력을 노트북에 쓴다. 실패하면 그 셀을 고쳐 같은 커널에서 이어 실행하고, 끝나면 `stop`한다. 외부 API를 호출하는 노트북은 검증 때 다시 실행하지 않고 저장된 출력으로 확인한다.

## 결과

`.claude/skills/meet-rag/scripts/nb_kernel.py`, `.claude/rules/notebook.md` §8, 오류 처리 절, `slice-verifier`. 임시 노트북으로 오류 후 이어 실행할 때 앞 셀 상태가 남는 것을 확인했다.

## 삭제 조건

노트북 실행 도구가 지속 커널과 이어 실행을 기본으로 지원하게 될 때.
