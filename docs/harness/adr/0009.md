# ADR-0009 근거 노트북을 결정보다 먼저, 사용자 결정을 반영한 뒤 PR

- 상태: 채택
- 날짜: 2026-10-02
- 커밋: 7372de0

## 맥락

PR #15 사용자 코멘트: 노트북은 프로젝트 결정의 근거 자료인데 S4는 D-04 결정 뒤에 노트북을 썼다. 또 PR을 올린 뒤 사용자 결정을 반영하느라 PR을 고치는 일이 여러 번 있었다.

## 결정

데이터·점수를 보고 정하는 결정은 근거 노트북을 먼저 쓰고 사용자에게 보인 뒤 DECISIONS에 기록한다. 결정이 걸린 조각은 지시서에 노트북과 결정의 순서를 적는다. PR 내용이 사용자 결정에 따라 바뀌는 작업은 결정을 반영해 마무리한 뒤 PR을 올리고, 사소한 결정만 PR 코멘트로 받는다.

## 결과

`.claude/skills/meet-rag` "결정과 PR의 순서" 절과 A1·A5·B6·D4, `.claude/rules/git.md` PR 절. S5·S6에서 노트북 → 사용자 확인 → DECISIONS → PR 순서로 진행했다.

## 삭제 조건

사용자가 PR 운용 방식을 바꾸거나, 결정 근거를 노트북이 아닌 다른 기록으로 남기기로 할 때.
