# ADR-0003 GPU 작업은 Colab CLI로, 오케스트레이터 E절

- 상태: 일부 대체(→ 0006, 0010)
- 날짜: 2026-10-01
- 커밋: 269ed92, f7d83a6

## 맥락

임베딩(KURE-v1 등)을 직접 해야 하는데 로컬 PC에는 GPU가 없다(SPEC 자원 제약).

## 결정

`colab` CLI 사용법을 `colab-operator` 스킬로 두고, 오케스트레이터 E절에 GPU 작업 절차를 둔다: 사용자 승인(GPU·예상 시간·compute unit) → 지정 GPU 할당, 실패 시 T4 → 실행·기록 → VM 정리. VM은 사용자에게 물을 수 있는 메인만 만든다. `slice-verifier`와 `protocol-guard`는 Colab 산출물을 내려받은 파일로만 확인한다.

## 결과

`.claude/skills/colab-operator`, `.claude/skills/meet-rag` E절, `slice-verifier`, `protocol-guard`. 실행 절차는 ADR-0006이 스크립트로 바꿨고, 질의 업로드 금지는 ADR-0010이 바꿨다.

## 삭제 조건

상시 GPU가 있는 실행 환경이 생기거나, 임베딩을 직접 하지 않는 구성(API 임베딩 등)으로 바뀔 때.
