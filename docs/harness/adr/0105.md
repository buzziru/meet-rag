# ADR-0105 판단이 없는 worker 일은 opencode CLI로 한다

- 상태: 채택
- 날짜: 2026-11-06

## 맥락

- 사용자는 worker가 필요한 일에 opencode를 쓰기로 했다(2026-11-06). worker는 기획, 검증, 감사, 판정처럼 판단이 필요한 일을 뺀 작업이다
- 모델은 `deepseek-v4.1-flash`와 무료 스텔스 모델 `crouton-alpha-free`, `pulse-alpha-free`다. 스텔스 모델은 judge에는 쓰지 못했지만 worker로는 쓸 가치가 있다고 사용자가 봤다
- opencode는 지금까지 judge용 API(D-38)로만 썼다. 조사·탐색 worker는 웹 조회와 파일 읽기 같은 도구가 필요하다. API로 하려면 도구 호출 반복을 직접 짜야 해서 CLI(`opencode run`)를 쓴다
- 첫 사용(GitHub trending 디자인 스킬 조사)에서 두 번 실패했다. 표준 입력을 닫지 않아 20분 동안 모델 호출 없이 멈췄고, 여러 줄 지시를 메시지 인자로 넘겨 첫 줄만 전해졌다. 지시를 파일로 첨부하고 입력을 닫자 끝났고, worker가 적은 별 수와 라이선스는 메인이 `gh api`로 대조해 같았다
- 작업 중 질문·보고를 주고받는 방식(Orca 감독 worker, `opencode serve`)도 검토했다. 사용자는 한 번 호출하는 방식으로 먼저 운영하기로 했다(2026-11-06)

## 결정

1. 판단이 없는 일(조사, 탐색, 정해진 형식으로 옮기기·모으기)은 opencode worker로 하고, 기획·검증·감사·판정은 Claude 서브에이전트로 둔다. 하네스 에이전트(`protocol-auditor`, `pr-briefer`, `slice-verifier`, `exp-judge`)는 바꾸지 않는다
2. 부르는 방법은 `doppler run -- opencode run "<짧은 메시지>" --dir <스크래치> --agent plan -m <모델> -f <지시 파일> < /dev/null`이다. 키는 Doppler로 넘기고 `opencode auth login`을 쓰지 않는다(평문 `auth.json`). 세부와 멈춤 확인은 `meet-rag` `references/worker-pool.md`에 둔다
3. 모델은 `opencode-go/deepseek-v4.1-flash`, `opencode-go/crouton-alpha-free`, `opencode/pulse-alpha-free`다. `opencode/`는 Console 종량제 경로라 무료 모델만 쓴다
4. AI Hub 데이터와 그 산출물을 넘기는 worker 일은 처리처 확대 승인을 먼저 받는다. 허용 처리처의 opencode Go는 judge용으로만 올라 있다
5. 한 번 부르고 끝나는 방식만 쓰고, 이어서 지시할 때는 `-s <세션 id>`를 쓴다

입력→동작: 디자인 스킬 후보 조사는 위 명령으로 deepseek-v4.1-flash에 맡기고, 후보 중 무엇을 쓸지와 근거 대조는 메인이 한다. G3 재판정 같은 판정 일은 Claude 서브에이전트로 한다.

감수하는 것: worker는 지시로만 범위를 제한하고(`--agent plan`은 파일 편집만 막는다), 스크래치 폴더 밖 읽기를 강제로 막지 않는다. 스텔스 모델의 입력 처리 조건과 `pulse-alpha-free`가 Console 경로에서 실제로 무과금인지는 확인하지 않았다. 첫 사용 때 Console 사용량을 본다. worker가 중간에 묻지 못해 지시가 틀리면 끝난 뒤에야 안다.

## 결과

`.claude/skills/meet-rag/references/worker-pool.md`(누구에게 맡기나, opencode worker 절), `.claude/skills/meet-rag/SKILL.md` 작업자 풀 안내.

## 삭제 조건

opencode 구독을 끝내거나, worker 실패가 반복돼 Orca 감독 worker 같은 대화형 방식으로 바꾸면 새 ADR로 대체한다.
