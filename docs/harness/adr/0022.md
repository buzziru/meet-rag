# ADR-0022 CLAUDE.md 명령 절은 호출법만 둔다

- 상태: 채택
- 날짜: 2026-10-07
- 커밋: (PR 병합 후 기록)

## 맥락

CLAUDE.md "명령" 절이 SLICE마다 길어졌다. 사용자 리뷰(2026-10-07)는 길이보다 성격이 다른 정보가 한 목록에 섞인 것을 문제로 봤다. 어느 세션에서나 쓰는 호출법, 특정 작업에서만 쓰는 절차(dev-full 질의 임베딩의 Colab 경로, 생성 옵션·API 한도, multi-doc 순서), 판단을 바꾸지 않는 부가 정보(수 초짜리 소요 시간, 결정 번호 참조)가 함께 있었다. 원인은 "파이프라인 명령은 SLICE가 끝날 때 여기에 추가한다"는 규칙이 추가할 범위를 정하지 않은 것이다.

리뷰는 multi-doc 줄의 Jev 승인 문구를 "금지" 절 OpenRouter 규칙과 중복으로 봤다. Jev는 OpenRouter가 아니라 별도 API(`src/rag/multidoc/check.py` `ask_jev`)라 "금지" 절에 들어 있지 않았다.

## 결정

- 절 머리에 기준을 둔다: 한 줄에 명령 하나와 호출법만, 옵션·절차·한도는 SLICE 문서나 DECISIONS에 두고 경로만 단다. SLICE가 끝나면 호출법만 추가한다
- 수 초짜리 소요 시간과 결정 번호 참조를 뺀다. Colab 전체 인덱스 약 21분은 승인 보고에 쓰여 남긴다
- 옮긴 세부는 이미 있는 문서로 링크한다: 인덱스 옵션 `slices/04-index.md`, 질의 임베딩 경로 `slices/05-retrieve.md`, 생성 옵션·API 한도 `slices/06-generate.md`. 생성 한도는 스킬이 아니라 문서에 둔다. 스킬 없이 생성을 돌려도 "금지" 절의 대량 실행 보고에 한도가 필요하기 때문이다
- 생성 줄의 "5xx는 서버 상태부터 확인"은 남긴다. ADR-0012 규칙은 스킬 오류 처리 절에만 있어, 스킬 없이 생성을 돌릴 때 닿는 곳이 이 줄뿐이다
- `chunk_sweep` 줄을 뺀다. D-04로 결론이 났고, H9가 쓰는 것은 명령이 아니라 산출물이다
- "금지" 절 유료 API를 "(OpenRouter, Jev)"로 넓힌다
- multi-doc 세 줄은 그대로 둔다. 검사를 Sonnet 에이전트로 바꾸는 S8c(`feat/s08-checker-agent`)가 병합되지 않아 main 코드는 아직 OpenRouter 검사다. S8c 병합 뒤 순서 절차를 meet-rag 스킬로 옮기고 CLAUDE.md에는 한 줄만 남긴다(대기 항목 22)

## 결과

`CLAUDE.md` "명령"·"금지" 절, 이 ADR과 목록.

- 검증: 뺀 세부(청크 크기 옵션, `export-queries`·`embed-queries`, `ask.query`, 프롬프트 버전·스트리밍, RPM·TPM)가 링크한 SLICE 문서에 있는지 확인했다

## 삭제 조건

없음. "명령" 절의 작성 기준이 바뀌면 상태를 고친다.
