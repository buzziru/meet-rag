# ADR-0108 Space 공개 뒤 화면 검증에서 토큰 문장을 지운다

- 상태: 채택
- 날짜: 2026-11-09

## 맥락

- ADR-0099와 ADR-0101은 비공개 Space에 페이지를 연결하던 시기(D-88 결정 3, S47)의 규칙이다. 토큰이 든 브라우저로 채팅까지 점검하고, 다른 주소에 토큰이 필요하면 `aside repl` 스크립트로 옮기며, Space 응답 값은 토큰 스크립트로 확인했다
- S41에서 Space를 공개하고 페이지의 토큰 연결 코드를 지웠다(D-92). 사용자는 S47 브라우저 토큰을 폐기했다. 미리보기 주소도 토큰 없이 채팅까지 된다
- ADR-0101 삭제 조건이 "토큰 코드를 지우는 S41에서 토큰 옮기기 문장을 지운다"였다

## 결정

`meet-rag` "화면 검증" 절의 대상 주소 항목에서 토큰 문장(토큰이 든 브라우저 점검, 토큰 입력 재요청 금지, `aside repl` 토큰 옮기기)을 지운다. 미리보기 주소에서도 토큰 없이 채팅까지 점검할 수 있다고 적는다. Aside가 브라우저 저장소를 읽지 않는다는 제한은 남긴다. Space 응답 값 확인은 토큰 스크립트 대신 Space API를 직접 부른다고 적는다.

입력→동작: 병합 전 페이지의 채팅 표시 점검은 그 브랜치의 미리보기 주소를 Aside에 넘기고 토큰을 옮기지 않는다.

## 결과

`.claude/skills/meet-rag/SKILL.md` "화면 검증" 절. ADR-0099의 토큰 브라우저 점검 문단과 값 확인 수단(토큰 스크립트, 결정 첫 문단과 결과 절의 입력→동작), ADR-0101 결정 2(토큰 옮기기)를 이 결정이 대체한다.

## 삭제 조건

Space를 다시 비공개로 돌리면 화면 검증의 연결 방법을 새 ADR로 정한다.
