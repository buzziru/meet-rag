# ADR-0093 SLICE가 gen-full을 돌릴 때도 생성 EXP 실행 절을 읽는다

- 상태: 채택
- 날짜: 2026-11-05

## 맥락

gen-full 실행 규칙(추적 끄기 D-71 등)은 `references/gen-exp.md` "B3 실행"에 있고, `meet-rag`는 그 문서를 B 흐름의 생성 EXP에서만 읽게 한다. S42는 SLICE로 gen-full을 돌리면서 v14·v15 실행에 `LANGSMITH_TRACING=true`를 써 D-71과 어긋났고 추적 업로드 429가 났다(`docs/slices/42-answer-format.md` 중간 결과 절). 수치에는 영향이 없었다.

## 결정

A 흐름 구현 단계에 gen-full을 돌리면 먼저 그 절을 읽으라는 한 문장을 둔다. 규칙을 옮겨 적지 않고 가리킨다. 훅은 두지 않는다.

## 결과

`.claude/skills/meet-rag/SKILL.md` A2에 반영했다.

## 삭제 조건

gen-full 실행 규칙을 `references/gen-exp.md` 밖으로 옮기면 그곳을 가리키게 고치고, gen-full을 SLICE에서 돌리지 않게 되면 지운다.
