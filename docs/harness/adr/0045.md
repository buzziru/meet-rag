# ADR-0045 S13 종료 뒤 `colab_job.py upload --allow-test` 제거

- 상태: 채택
- 날짜: 2026-10-19

## 맥락

- `colab_job.py upload --allow-test`는 검색 단계 종료 test 1회 실행(S13)에서 test 후보 쌍을 Colab에 올리려고 넣었다(ADR-0043). 그 1회는 2026-10-19에 끝났고 결과는 D-39에 기록됐다(PR #101). 같은 설정으로 다시 실행하지 않는다
- 옵션이 남아 있으면 이후 작업이 test 질의를 Colab에 올려도 스크립트가 막지 못하고, PR 전 감사(protocol-guard P6)에서야 드러난다. ADR-0043 삭제 조건이 실행 뒤 제거 검토를 요구한다

## 결정

- `colab_job.py`에서 `--allow-test` 인자, `non_dev_qids`의 `allow_test` 매개변수, `upload`의 허용 분기와 메시지를 지워 ADR-0043 이전 동작(dev 질의만 통과)으로 되돌린다. 해당 동작 테스트도 지운다
- meet-rag E6과 오류 시나리오에서 옵션 서술을 지운다. protocol-guard P6에는 test 1회 실행(S13)이 2026-10-19에 끝났다는 사실(D-39)만 남긴다

남긴 것: `rag.eval.score --allow-test`와 `search.allow_test`는 프로젝트 코드의 test 경로 차단 장치라(S3·S13) 이 하네스 변경의 대상이 아니다.

## 결과

`.claude/skills/meet-rag/scripts/colab_job.py`·`test_colab_job.py`, `.claude/skills/meet-rag/SKILL.md`(E6, 오류 시나리오), `.claude/skills/protocol-guard/SKILL.md`(P6), ADR-0043 상태.

## 삭제 조건

- 없음. test를 다시 Colab에서 처리해야 하는 결정(평가 프로토콜 변경)이 생기면 그때 새 ADR로 정한다
