## 생성 단계

gen-full(판정용 330질의) 종합 지표(충실성·관련성 평균), 기준 대비 차이는 회의 단위 paired bootstrap 95% 구간(SPEC "생성 단계 평가 > 판정", D-53). 생성 평가는 전체 거부 등으로 계산하지 못한 질의를 빼므로 계산한 질의 집합이 실행마다 다르다. 기준 종합 지표는 기준 실행 단독 값(기준에서 계산된 질의)과 짝지은 값(기준·후보 모두에서 계산된 질의)을 둘 다 적고, 후보와 차이·구간은 짝지은 값이다. 괄호는 질의 수다.
