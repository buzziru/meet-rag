# SPEC 정리 초안

이 초안은 SPEC으로 옮겼다(D-65, 2026-11-03).

`docs/SPEC.md`(main 6fc906a)를 고칠 문장의 초안이다. 승인을 받으면 SPEC과 다른 문서에 옮긴다(`docs/CLAUDE.md` SPEC 절). 줄 번호는 지금 SPEC 기준이다. 긴 줄은 바뀌는 조각만 적었다. 판정 규칙(δ, 안전 조건, 재표본, 지표 정의)은 바꾸지 않는다.

## 답이 필요한 곳

나머지는 앞서 "추천대로"로 정한 것을 문장으로 옮겼거나 결정·코드에 맞춘 것이라, 의견이 있는 줄만 답하면 된다.

**A. `:182` 재검증 규칙.** 지금까지 D-60 결정 4와 D-63 결정 9의 실행 방식이던 것을 일반 규칙으로 올린다. 다음 지시 버전(j_v12)을 만들면 같은 생성 기록을 j_v11과 함께 채점해 차이를 D-50 변동 폭과 사례 대조로 보고, 기준과 후보를 j_v12로 채점한다. 사람 대조는 요구하지 않는다. 메인 판단: 그대로 둔다.

**B. `:182`에서 지우는 블라인드 절차.** 표본 30\~40개 층화와 "기준값에 못 미친 기준은 보조 지표로 내린다"를 지우고, 사람 대조를 다시 하면 P5와 미결 4 구간을 따른다고 적는다. 층화·표본 수는 P5와 미결 4에 없고 S25 지시서에만 남는다. 다시 할 때 S25 도구(`rag.gen_eval.blind`)를 이어 쓰므로(D-51) 메인 판단: 지운다.
